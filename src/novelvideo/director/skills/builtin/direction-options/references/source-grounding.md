# Source-grounded outline adaptation

Adapted from short-drama `adaptation-core.md` and `event-coverage.md`: preserve key event coverage and distinguish approved changes from the source. This is a bounded outline adapter, not a claim that the full chapter inventory or source-audit pipeline has run.

Before expanding an outline, identify the actual event chain: who acts, what they know, what changes, and how the ending occurs. Preserve order and causes unless the user explicitly approves a change. A compressive outline can merge exposition but cannot silently delete a rescue, transfer an action to another character or turn a witness into its actor.

Separate three kinds of evidence:

- An event narrated as happening can anchor synopsis and actions.
- A character's explanation or warning stays attributed to that speaker. Conflicting explanations do not become a single objective world rule merely because it reads more smoothly. State the competing claims and the observed event; put the unresolved mechanism in assumptions as a question.
- An ending may retrospectively mention an earlier action that was never staged. Preserve the observed ending, but do not claim a precise cause, motive, timing or prior setup has already been shown. Mark the missing bridge and ask where/how it should occur before a later screenplay fills it in.

For each gap, name the exact affected event and give the smallest useful question. If proposing a bridge, label it explicitly as a proposal in assumptions, not an established scene. The same uncertainty must remain in synopsis, rules, segments and payoff tables; one disclaimer does not license contradictory certainty elsewhere. Do not put already supplied names or events in the unknowns list.

Do not manufacture escape requirements, punishment scope, time laws, personal history or psychological diagnoses to close the chain. “Character believes X” is not proof that X is a necessary condition. An image can prove that a trace remains without proving a new supernatural law. Keep the source's deliberate ambiguity when it does not prevent understanding the actual actions.

Use the original's concrete contrasts, decisions and emotional transitions as craft material. Faithfulness is not mechanical copying: show how invitation becomes temptation, information changes a choice and rescue alters the protagonist's valuation, where supported. Do not invent a price or loss merely to fill a cost field. When the source itself has a gap, an honest conditional outline is more useful than an unapproved solution disguised as fidelity.
