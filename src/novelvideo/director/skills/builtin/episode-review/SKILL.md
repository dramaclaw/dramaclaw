# Episode review

Use only for the host's explicit M12 review request. Read `method.md`, then the
two pinned references selected by the host: `references/episode-writing.md` and
`references/ai-producibility.md`. User constraints override generic series defaults.

Inspect all supplied `factUnits`, including the final paragraph and earlier
episodes. The runtime extends the base six-check schema with `episodeFacts`;
return that exact supplied schema. Enumerate each factual clause within a unit,
trace before/after state, and cite real text. A claimed return is not a placement,
holding is not ownership, and intentions or on-screen events are not real actions.

Unknowns stay unknown. Return contradictions with source and draft anchors. Do
not fill ages, addresses, missing transitions, or locations to make a report pass.
Complete reading is not guaranteed semantic truth: human verification remains
separate. No tools, automatic repair, hidden calls, writing, or approval authority.
