# 单集写作

按 3–15–45 的相对节奏检查开场状态、中心冲突和首次价值变化，并随单集目标时长缩放。每集先确立一个可见问题，再让人物在本集采取可拍摄的行动并产生已发生、可观察的结果；结尾钩子在该结果之后另开新问题，不以“下集再解决”替代本集闭环。

字数服从目标时长和表演节奏，不固定套用 800 字。先估算台词朗读时间，再计入动作、停顿与转场；有成片样本时才用实测时长校准。

## 单集写完后的可执行复核

- **场次因果**：逐场标明人物目标、阻力、采取的动作和可见结果。删去场次后若本集结局不变，该场可能只是在解释主题；若高潮靠一句台词宣布，而没有先前可见行动，则补行动而非补旁白。
- **对白盲测**：遮住说话人标签，抽取两名以上主要角色的台词。若互换说话人后仍成立，就从其身份、利益、知识范围、措辞习惯与此刻情绪中找差异；不要只用口头禅制造区分。关键转折台词要让对方的行为发生变化。
- **角色能动性**：检查受害者、爱慕对象和对手是否各有可见选择与代价。救人或拒爱不能只作主角的成长道具；允许主角行动与他人的选择同时成立。
- **场景可拍性**：每个场次头交代内外、具体地点、时间及在场人物；动作写清主体、对象、空间位置和可见结果。相邻场景的出入口、道具归属、文书流向与时间跳跃必须能接上。景别提示不等于可拍，不能靠镜头隐藏核心因果。
- **时长复核**：把朗读台词、静默反应、动作、字幕及转场分别估时。纸面目标时长只是待排演假设；未试读、未分镜时不得声称已满足成片时长。

历史/传记改编时，再把重要陈述分为“有来源的史实、项目锁定设定、艺术加工”，标注具体依据；姓名、亲属、官职和先后顺序逐项核对。若为了节奏压缩真实事件间隔，应在场次或字幕中交代，不能让观众误以为同日发生。此条只在相应题材启用，不把个案写成所有短剧必须遵守的史实规则。
