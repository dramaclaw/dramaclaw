name: character-bible
description: Generate or revise TV Director character biographies, scene designs and prop designs from confirmed story facts, using routed short-drama methods and the host's structured output contract.
---

Read [method.md](method.md) for the field mapping and source/unknown rules. Read
[character-craft.md](references/character-craft.md) for the routed short-drama
character-design method. For scenes read [scene-craft.md](references/scene-craft.md).
For props read [prop-craft.md](references/prop-craft.md).
The runtime routes only the selected document's craft; preparation loads all three.
It also loads the shipped producibility note.

The host chooses character-only, scene-only, prop-only or full preparation schema and freezes the
input versions. Return a proposal only; the host validates episode references,
retains the raw response, and asks the user before adoption. A valid schema is
not evidence that motivations, relationships or literary quality are correct.
