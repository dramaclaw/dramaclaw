# 互动影游制作规划

用于整部影游或部分片段的制作方案、参数、素材、尾帧和生成就绪检查。复用虾塘资产、现有节点参数和提示词；不新建资产库、设置页面、故事结构或隐式全局默认字段。

制作计划或参数写入不授权视频生成。仅用“已规划／参数已写入／提示词已准备／素材待补齐／可生成”描述经过对应核验的状态；缺少真实素材、能力信息或回读结果时不得宣称就绪。实际执行另读 [generation-execution.md](generation-execution.md)。

## 读取现状

先 Get 故事和当前画布，将 Segment 对应到真实视频节点。剧情关系以故事工具为准，生成参数和已连接素材以节点详情为准。使用当前会话提供的 `freezone_get_node_detail` 读取 `parameters`、`reference_media`；需要动作参数时读取 `freezone_get_node_action_catalog`。不能从标题推断节点 ID、模型 ID 或素材用途。

收集已有视频、当前提示词、`model`、`genMode`、`durationSec`、`aspectRatio`、`quality`、`generateAudio`，以及人物、场景参考是否就绪。模型从工具返回的当前 options 中选择，并核对参考类型和数量、声音、时长范围及清晰度档位。不凭记忆指定模型能力或价格；无法读取时列为待核实。

## 集中规划与审核

用户侧将制作规划合并为“审制作”，不要逐项询问或要求逐节点配置。先给推荐摘要：风格、主要路径观看时长、公共画幅与声音、主要资产、例外和待解决事项；逐段细节按需展开。用户可以一次提出多个例外，Agent 联动调整受影响的参数、时长、参考与提示词。

整部制作需整理人物、场景、关键物品及使用片段，区分已有素材、用户待提供素材和待制作素材。记录影响连续性的外观、服装、物品状态与位置，并检查分支汇合是否兼容。不要求每件物品都有独立参考图，也不把文字设定视为已有素材。局部请求只整理涉及的资产。

观看时长按起点到结局的路径估算，区分主要路径预算、可核实的最短/最长路径和全部分支素材的制作总时长；不能把全部节点秒数当成一次游玩时长。条件路径或循环使范围无法可靠确定时，注明覆盖和假设；开放等待与无限循环没有有限最长时长。玩家选择等待、倒计时和互动循环与主视频分别计算。

逐片段优先采用已有配音实际时长；否则按对白自然语速、动作、画面文字阅读、表演停顿和收尾估算。并行动作不重复相加，先后事件需留足时间。将估算匹配模型实际时长档位；超出能力时提出简化镜头或拆分建议，未经同意不拆剧情节点，也不依赖前端静默限幅。

默认整部共用模型、画幅和清晰度，但保留明确例外。没有共同可用模型时，说明具体冲突并提出最少例外，不静默替换用户选择。

`production_notes` 应说明场景、参与人物及稳定外观、可见动作、镜头、对白和声音意图、开场与收尾构图，以及相邻片段的连续性。`video_prompt` 只描述当前片段可见且可拍摄的内容，不复制剧情原文，也不包含条件、变量、开关或结局路由。分支汇合片段采用兼容所有来源的开场，不能默认玩家来自其中一条路径。

## 参考和首尾帧

- 只规划真实可定位的人物、场景和产品素材；人物身份记录本身不等于已绑定图片，缺失素材列为待补项。
- 剧情选择线不是媒体参考。判断汇合时按不同前置视频节点计数；多个选项来自同一视频只算一个来源。
- 单一前置视频且同场景连续动作时，可规划承接其尾帧；多来源汇合默认使用人物/场景参考和共同兼容的开场，不任意选择一条路径尾帧。
- 首帧模式只接受一张开场图。需要人物图、场景图和尾帧等多份素材时，选择支持多图的参考模式或先制作合成开场图；全能参考不保证严格复现开场图。

规划阶段逐段记录镜头承接建议（“独立开场／自动承接指定前片尾帧／多上游汇合：指定承接来源或独立开场”）、真实来源节点、预期收尾状态及后片动作。来源未生成时标记“待前片生成后提取”；可以写入 `production_notes`，但不得编造 URL、素材 mention 或已就绪状态。

审制作阶段默认逐段给出镜头承接建议，不等用户开口：单一前置视频且同场景连续动作→自动承接（`auto`）；换场、跳时间或无前置→独立开场（`independent`）；多上游汇合→默认独立开场，仅用户点名来源时设 `continuitySourceNodeId`。方案获批后先核对动作目录中的 `continuityMode`，宿主支持时批量将已确认连续的片段设为 `auto`，一般换场片段设为 `independent`；若用户要求先从前镜尾帧开场再换场，可设为 `auto`，并在视频提示词中写清从截图到新场景的可见转场，不得直接以新场景开场。这些是视频节点制作字段，不写入 StoryDraft。获批后不另外逐分支执行截图和绑定，也不重复询问已授权的承接操作；切换为独立开场时，宿主会立即清理旧自动承接连线与提示词段，无需手工处理。

开启后，生成入口按实际前置视频提取或复用尾帧，同源分支共享截图，并自动绑定首帧槽位和实际参考编号；模型及模式仍使用已确认设置。批量运行会按开启承接的依赖顺序执行。源视频换版仅在下次生成下游时更新参考，不自动重做已有成片。多图参考仍不保证严格首帧一致；自动承接也不等于已经目视检查画面。自动承接的提示词段在生成时按实际参考编号写入，不会在切换模式时预写。

自动承接只负责尾帧。若计划让全能参考同时使用人物、物品图片，生成前先找到真实图片节点，用 `create_edge` 的 `media_input_for` 连到目标视频并回读引用列表；缺少素材则列为待补，不把提示词里的“使用人物参考图”当作已绑定。宿主会按实际图片顺序在影游提示词开头写入尾帧首帧说明和已连入图片的 `@图片N` 用途；不要预写或猜测编号，不能把未连入的图片写成已引用。

需要提前审查尾帧、用户只要求截图，或宿主尚未提供自动承接字段时，手动准备真实尾帧：

1. 先读取来源视频的动作目录；当前支持 `capture_video_last_frame` 时，用 `run_node_action` 单独截取当前选用视频尾帧，取得返回的 `createdNodeId`、图片地址和来源信息，并回读核对来源视频 URL／版本。该操作只准备素材，不提交视频生成；缺少该动作时标为待人工处理，不凭文件名认定来源。
2. 检查构图、姿势和道具是否符合衔接意图；明显冲突时报告，不擅改剧情。
3. 按已确认模式绑定并回读真实素材 mention。说明尾帧用于开头、人物图用于身份、场景图用于环境；全能参考仍需成片核验。
4. 从真实尾帧状态完善后片提示词，再核对时长和节点参数。

需要提取当前成片的开场参考，或对照“前片尾帧 → 后片首帧”的连续性时，先读取来源视频动作目录；支持 `capture_video_first_frame` 时，用 `run_node_action` 单独截取当前选用视频首帧。回读返回的图片节点和来源 URL／版本，再按用户已批准的用途使用；截帧本身不自动绑定参考或授权生成。缺少动作时标为待人工处理。仅能读取素材元信息时，不宣称已看图或验证人物、道具、构图一致；首帧图作为参考也不保证生成严格复现。

来源视频重新生成或切换版本后，重新核对旧尾帧和受影响片段。未开启 `continuityMode=auto` 时，剧情连线不会自动成为媒体依赖；普通工作流只有在契约支持且计划确认了单来源连续镜头时才使用实际视频 `dependency_for` 输入。这里的 `dependency_for` 指节点详情或运行工具契约中声明的媒体依赖字段，不得从剧情边推断。汇合片段不批量添加多条视频依赖。

## 提出并应用计划

集中审核内容包括：片段、人物/场景/关键物品、建议秒数及依据（对齐模型实际时长档位）、模型档位和生成模式、镜头承接模式与承接来源、参考及尾帧方案、提示词草稿、缺失项；公共画幅、清晰度和声音策略放在摘要，标出逐段例外与已有成片。提示词草稿遵循 [prompt-fidelity.md](prompt-fidelity.md)，未绑定素材用自然语言注明用途和待补项。

确认后重新读取受影响节点，保留用户期间的新改动，只写已批准字段和片段：

- 单节点参数用 `freezone_update_node_data`；多节点先读取命令契约，再用一次 `freezone_emit_canvas_command` 的 `canvas_chat_commands.v1` 批次，每项 `update_node_data` 写真实 `node_id` 和 `data`。
- 节点参数字段为 `model`、`genMode`、`durationSec`、`aspectRatio`、`quality`、`generateAudio`。不要写 API 请求字段 `durationSeconds`/`resolution`，也不要把这些设置塞进 StoryDraft 或提示词。
- 素材引用仅按已批准方案创建或替换。设置后回读 `reference_media` 的准确 mention 与用途，不自行编号或沿用失效引用；只有素材元信息时，不声称已检查图片内容。
- 提示词通过故事 Patch 的 `update_segment.changes.video_prompt` 写入；同一阶段合并多个片段为一次原子写入。新尾帧到位后的后续阶段可再次写入，但每次先 Get 最新故事并保留 script、media、分支和用户编辑。
- 多步写入不是事务。逐阶段核对结果，失败时报告已应用项和待处理项，不盲目重放批次。

## 宣布可生成前逐片段核验

仅核验本次涉及的片段，并复用内容和配置未变的已核实结果：

1. 时长有对白或动作依据，且符合模型当前支持的档位。
2. 开场与收尾兼容前置片段；汇合点的机位、人物、动作和道具状态兼容所有来源。
3. 必需参考真实可用；手动尾帧已核对来源版本、提取并绑定；自动承接则核对配置和真实来源，上游视频已完成或包含在本次获授权的生成批次中，报告“生成时自动准备尾帧”，不要声称尾帧已生成。
4. 参数、提示词和引用均已回读验证。

任一必需项未知或缺失时保持待准备。仅获准修改文案时保留参数并报告未核实项。执行器不会解析制作备注自动完成这些检查，也不存在持久化的“整部默认设置”自动继承机制。
