# 剧情到视频提示词

准备或修正 `video_prompt` 时，先读最新 `script`、`production_notes`、节点参数与真实 `reference_media`。只把已确认剧情转换成当前镜头可拍内容。

- 保留事件顺序、人物意图、结束状态，以及对白、旁白、手机消息、标牌和字幕的原文与呈现位置；汇合镜头不假定玩家来自某一分支。不能用表情或“显示文字”替代具体台词。
- 可补景别、光线和运镜，不新增改变情节的动作或提前发生的情绪结果。人物、场景、产品和分镜图须先真实连入视频；宿主按引用顺序补齐缺失的素材 mention 与用途，Agent 不猜编号、不重复写托管素材段。身份参考图的姿势不覆盖本段动作。尾帧开场须描述如何从该状态继续。只有素材元信息时不声称看过图片。
- 播放器 Choice 不会自动生成视频中的消息、字幕或按钮。精确文字保留在提示词并在成片核验；选择后期处理时记录待完成的原文与位置。视频内按钮要可点击，成片后仍须按 [交互选项](interaction-options.md) 配置热点并核验位置；未成片不猜坐标，也不重复叠加同文案播放器按钮。
- 检查对白与动作能否容纳在当前 `durationSec`，冲突时报告，不静默删台词、加定格或拆剧情。仅修提示词时保留模型、时长、画幅和声音设置；写“竖屏”不等于参数已改变。
- 只在选择等待或尾帧承接需要时要求稳定收尾。装饰 UI 和视觉倒计时不等于真实交互、数值统计或超时逻辑；按实际播放器能力设置行为。

写入时只 Patch 目标片段的 `video_prompt`，保留剧情、选项、媒体与已有视频，并回读核对原文、引用和未解决的制作限制。
