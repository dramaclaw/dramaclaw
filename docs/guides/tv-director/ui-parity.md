# TV Director UI 对齐验收 · 2026-09-26

用户要求界面、操作与图标全面对齐 LibTV。本文件以第二批续轮结果为当前事实，替代第一批“设置/历史仍为旧布局、编辑器仍为 textarea”的状态。第一批历史结果保留在任务台账；局部通过不等于完整 TV Director 已交付。
完整业务差距见 [implementation-closure.md](implementation-closure.md)，按钮语义见 [feature-contracts.md](feature-contracts.md)。

## 1. 来源与验证边界

- 参考 [LibTV 画布](https://www.liblib.tv/canvas) 当前登录态可见 DOM、SVG、公共装饰图与同视口截图，不只凭截图推断。
- 使用 Playwright 技能点击、测量、截图；复用本机忽略的登录态，未打印/复制凭据。只读打开原站新对话/设定器/设置/编辑器，未确认改动其原稿、未提交生成、无新模型费用。
- 本地浏览器使用真实 DirectorStudio、样式、Director API/SQLite；tests/director/preview_execution.py 提供隔离合成作品及无供应商模型。历史写动作真实落存储，不是纯前端演示；但不是生产登录、真实模型质量或 Windows 验收。
- 不改旧画布、用户原稿、供应商模型或付费权限。Tiptap 为第三方富文本依赖，没有复制原站客户端业务源码或服务端私有 Skill。

历史接口为 POST works/{id}/history 的独立严格命令：command_id + expected_revision + action + title?，事务保存回执、校验身份/工作版本。归档只加标记，不删正文/版本/费用/运行结果；响应不确定时只能重试同一意图，不能换行偷换目标。重复打开当前作品不会再清空正文。

Top8权威配置为 assets/preset-templates.json。特别修正：现实职场成长融合“职场行业”，仙门团宠融合“古装言情”，重生复仇主题材为“家庭伦理”；八份模板全部字段均已对照，测试逐一核验实际应用与保留字段，显示和保存同源。

- frontend/public/director-reference/genre-00.webp 至 genre-13.webp：14张720×720公共题材图；“其他”用自定义SVG。

## 6. 尚不能标“全部对齐”的清单

1. **所有业务态未逐屏像素验收**：阶段执行/报价/质量/定稿/逐处差异仍有自有布局；改编高级字段非独立原站改编面板，自动集数未实现。
2. **块级/逐hunk审阅缺失**（E22–E29）：版本文字引用不是稳定选区重写；无上一处/下一处/单处接受撤回/关联会话完整流转。
3. **媒体引用与多节点画布不完整**（A14–A19、E07–E08）：文本文件/当前文档不等于图音视频资源库，不能说H3/角色图/全能创作已通。
4. **分享/插件/导演角色/Skill库未接通**（A06/A08/A21、R/K组）：方法说明弹窗不是Skill目录/收藏/我的/详情/创建界面，禁用入口不算完成。
5. **自动策略与跨设备设置未实现**（A22/Q09/S01–S03/S06–S07）：本机通知不冒称云设置，Token上限不是积分预算。
6. **全应用壳/Windows/触屏/全页像素差未验收**；隔离页不是项目实际导航壳；第三方素材再分发权待确认。
