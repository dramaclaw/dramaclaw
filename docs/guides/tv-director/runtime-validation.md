## 1. 本轮实际接入的行为（前轮历史）

- 页面从服务端取能力指纹，提交严格camelCase命令。预览冻结当前规格/文档版本、实际参数、prompt hash、system prompt hash绑定的能力版本及输出上限。
- 一个用户批准动作对应一个意图ID；网络失败重试批准复用该ID。相同ID不同参数409冲突；同事务保存approval、operation、cost reservation、outbox与事件，失败整体回滚。
- 派发前再次核对输入/能力。原子领取一次，派发后不因刷新、重复消息或租约到期而重新调用供应商。**这是本机at-most-once派发，不是跨网络exactly-once承诺。**
- 未派发取消和已知未发送的输入错误可记0调用；派发后断线/停止的费用仍未知，不伪称退款。过期在途任务转UNKNOWN并阻止新调用，待供应商核对。
- 正常回包只生成待审候选，不覆盖正式版本；版本已变、取消后回包、迟到结果保留但不自动采用；截断输出不标完整候选。
- Token usage/结束原因进入持久回执；若供应商回报模型名则单独保存，不据此宣称已验证底层权重。金额没有供应商结算证据时仍为null。
- 用户可从执行卡片查看保留原文，只读GET不会生成新意图/模型调用或采纳文本。跨作品ID及无项目权限不可读。
- 页面刷新读持久投影；切换作品丢弃旧预览。旧v1生成接口返回409升级提示，防止绕过授权；旧文档/历史读取保留。
- 设定器内编辑使用局部草稿，取消/ESC/遮罩不修改父级。确认才保存；已生成作品继续按当前规则只读设定，影响分析式改规格尚未实现。
