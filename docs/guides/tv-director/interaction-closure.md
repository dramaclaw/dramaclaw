## 2. 本次 LibTV 实际操作

复用本机被忽略的 storage state 登录；未在文档记录凭据。三个菜单确实是角色图、场景图、道具图。

1. 切换全能创作并发送附带剧本文档的场景任务。
2. 可见活动读取 3 份创作文本。
3. 创建 6 个待生成图片节点。
4. 请求确认 90 积分；本轮点了取消，没有批准图片执行。

原剧本文字未改，但已产生测试对话和待生成节点；不能称该次访问全程只读。可见余额仍为 930，不据此承诺文本规划免费或最终账单为零。本轮记录的是浏览器状态，不是已捕获的原站完整网络请求/响应。历史研究的原始网络证据仍在其原落点。本轮事实纠正此前“菜单等于素材选择器”的推断。

## 3. 自动保存的唯一写入路径

实现位置：`useDocumentAutosave.ts`、`DirectorDocumentEditor.tsx`、`api/director.ts`、`director/repository.py`。

- 使用现有 `document.commitManual`，不新增第二套正文存储。后端响应增加同一事务的 `workRevision`，随幂等响应持久保存。
- 每次编辑记录本地恢复稿；停止输入 1 秒后串行提交。该 1 秒是去抖，不是剧本时长、模型超时或生成上限。
- 请求绑定作品、文档 ID、正文版本、作品版本、commandId/clientRequestId；保存期间继续输入只会在前次确认后提交下一版。
- 无变化不提交。输入法组合期间、只读或忙碌时不提前保存半个输入。
- 丢响应保留原命令。重开先提示恢复，不自动重发；继续保存先重放原命令，再考虑之后的输入。409 不生成新 ID 绕过冲突。
- 关闭、Esc、切编辑栏目、选区引用、聊天栏目切换、继续打磨、打开别的作品和新对话都先保存；失败留在当前编辑器。
- 正式状态不会因为自动保存而自动采纳模型、审稿或定稿。生成按钮在未同步编辑时禁用。
- 冲突提供“下载本地副本并读取最新稿”：先 GET 最新正文/作品，下载本地副本，用户确认后只替换编辑区；不向服务端写正文。请求仍在执行或结果未知时不能用此入口丢弃原命令。
- 浏览器存储失败明确提示手动复制，关闭保护不假装已备份。恢复稿是会话级本地数据，不承诺另一设备可恢复。

主界面顶部显示待保存/保存中/已保存/失败/冲突；旧显式保存安全栏移入更多操作。私有草稿仍保留，不能把它与正式正文版本混为一谈。

## 5. 图片操作、真实参数与防重复提交

实现：`DirectorMediaPanel.tsx`、`director/media.py`、Director API 的薄适配路由；现有图片供应商实现不改。

### 接口

相对 `/projects/{project}/director/works/{work}`：

| 路径 | 行为 |
|---|---|
| `GET /media/source/{kind}` | 已保存文档版本、正文顺序的素材、视觉风格 |
| `GET /media` | 作品内持久化意图与任务回执 |
| `POST /media/prepare` | 校验并冻结素材、模型、参数、来源；不派发供应商 |
| `POST /media/{intent}/confirm` | 校验明确同意和未知金额确认，原子领取后调用既有任务服务 |

新增 `director_media_intents` 表，不修改正文表。prepare/confirm 分离；prepared→submitting→accepted/unknown。进程中断后的 submitting 不是可以重新购买的许可。相同 ID 不同参数/作品/用户拒绝；已领取的同 ID 再确认不重复派发。供应商结果不明保留 unknown，不自动重试。

### 输入来源

| UI | 冻结字段 | 说明 |
|---|---|---|
| 角色/场景/道具 | `kind` | 不通过模型猜目录 |
| 生成对象 | `asset_id`、完整原文段 | H2 顺序；旧关系/世界规则段不被当成角色；不附带下一个素材 |
| 可编辑提示词 | `prompt` | 默认含该段设计和作品画风；以用户最后确认文本为准 |
| 图片模型 | `model_id`、实际 model/provider | 服务器重新核对目录和指纹 |
| 比例/分辨率/质量 | `aspect_ratio/image_size/quality` | 从目录选择；目录空选项只用接口兼容默认值，并明确提示 |
| 高级参数 | `model_params` | 控件、类型、选项、必填、默认值来自实际模式 schema；服务端再次验证 |
| 引用/生成模式 | `reference_urls=[]`、`gen_mode=text_to_image` | 当前是设计文字出图，不冒称多参考图路径已实现 |

必选列表无默认值时显示未选择，未填完禁用准备；开关的可见初值与提交值一致。完整的**适配接口请求**可在确认卡展开查看；它不是未经适配的供应商线上原始报文。供应商 schema 映射仍由共享适配器负责，复杂模型的尺寸参数覆写关系需要专项供应商验收，不宣称已逐模型验证。

准备后来源版本/作品版本或目录改变，确认拒绝；不偷偷用最新稿替换已批准素材。金额未知明确披露并独立勾选，不显示虚构免费或价格上限。

任务状态读取现有项目任务服务；完成读取已持久化 job 结果。任务从短期列表移除后仍可按 job 恢复结果；读取失败不重启生成。当前每笔展示单个结果，不支持源站批量节点布局或多结果选择。

## 6. 事实与技能：从请求到待采纳门

保留 short-drama 的人物/场景/道具创作参考，使用 skill-creator 规范增量修改应用内 M08，版本 2.4.2；不改全局 short-drama。包 method、manifest、provenance、运行时允许版本和宿主 pin 一起更新。编译器 2.6.0。最后清理了“只有场景字段”与宿主新增 sourceProofs 的文字冲突；哈希变更会使旧未消费报价失效。

新单文档人物/场景请求：

1. 冻结来源、简报、锁定事实、已存大纲与用户指令，标记 inputId。
2. 人物具体数字年龄、称呼、语言/记忆点/受压行为；场景类型、空间限制、复用位置提供逐字段 `sourceProofs`。
3. 高风险文本字段在 schema 给原文片段或未知值；普通文学说明仍可解释既有事实，不得新增事件。
4. 宿主确认引用存在、主体匹配、字段完整值匹配。年龄不能借另一个人物的年龄；否定/禁止例不当事实。内外需要显式证据，不仅凭“会议室”等名称猜测；空间条件不当已执行动作。
5. 去除审计附属字段后仍走原严格人物/场景 schema。缺证据、不合法 JSON 或重复空间不创建可采纳变更，保留原回包与失败字段。
6. UI 原回包窗口展示 factAudit；不会修掉错误后假装模型原本正确，也不会自动再扣费。

该规则是有限、可审计的高风险门，不是通用语义证明。未扩到筹备 M08/M11 全文或所有语言表达；原文引证也不能保证全部因果/关系无误。未确认的历史文档不自动迁移为确认事实。场景前缀别名只用于找引证，去重保留室内/室外不同空间与画中空间，不草率合并。
