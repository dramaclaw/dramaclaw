# 完整 TV Director 的可执行验收合同

设计 v2.1 / 2026-09-25。属于[融合方案](../tv-director-skill-fusion.md)。下文阈值是**我方拟定的工程验收标准I**，不是未经测量就声称LibTV具有这些指标；测试计划不等于测试结果。完整目标需分别证明功能、操作/视觉、内容质量、运行安全，而不是只比按钮数量。

## 1. 交付状态与测试分母

交付分四级：设计已审 → 离线合同通过 → 真实单链通过 → 全产品验收通过。缺某阶段可以交付带范围说明的阶段版，不能改名为“完整TV Director”。

机器可读矩阵已落在 [implementation-map.json](implementation-map.json)：requirements逐项记录id/contract/commands/组件/用例/API/schema/方法/规则/fixture/测试/差异与结果；methods/rules/transitions/sourceRoutes分别覆盖方法、规则、转移、源Skill路径。designStatus=ready只表示规格闭合；status=not_implemented/implemented_unverified/pass/fail/blocked是产品状态，resultRef为空不能pass。N是源站证据等级，不能当pass，blocked也不是pass。

- 按钮分母固定为A26+O16+D9+Q9+S7+E32+R18+K20=137；补充X12，共149个动作合同。每行都有对应UI-ID自动/浏览器用例及公共状态用例，不允许隐藏未实现按钮减少分母。
- 能力C01–C08全链均计入；24方法包各有正负例，四改编策略各有同源差异验收；G01–G18各有触发/禁用/冲突断言。
- [工作流表](workflow-contracts.md)每一行转移至少一例合法和一例守卫失败，费用/取消/未知/完成后重开必须覆盖；不能只截取正常路径。
- 观察到的源站功能与我方兼容性例外分开；单集改编、末集人工定稿、硬预算等差异允许，但要明示，不宣称隐藏的内部逻辑相同。

## 3. 功能/API/运行安全门

| 门 | 必须通过 | 失败处理 |
|---|---|---|
| 参数一致性 | 每字段UI→Spec→snapshot→compiler→provider request→回显100%匹配或明确不支持；缺省/null/auto同样测试 | 一处不一致即阻断发布，不先调文案掩盖 |
| 状态 | 转移表覆盖100%；过期/重复/越权动作零非法推进 | 回滚本阶段实现，不改期望迎合错误 |
| 来源/语义 | gold关键事件召回1.0、锁定事实/台词错误0；非关键unknown可见；F04–F07通过 | 不能以平均分抵消关键失败 |
| 修订 | 选区外零变化；依赖组/CAS/原子性；正式/草稿与定稿区分 | 保存可恢复草稿，不覆盖正式内容 |
| 费用 | 每外部调用唯一operation/ledger；同幂等键无重复本地派发；所有阶段有授权范围 | 远端不支持幂等时UNKNOWN阻止重发，不能谎称远端exactly-once |
| 故障 | worker在预留/派发/回包/提交各断点重启；断流/重复/乱序/迟到可恢复 | 正式数据/审批不漂移，副作用未知可见 |
| 权限 | 另一project文档/素材/Skill读写均拒绝；恶意导入/路径/日志泄密0成功 | 安全缺陷阻断发布 |
| 迁移 | 旧样例升级重试无损；legacy不伪造审阅/费用；备份恢复checksum一致 | 保留旧数据与回滚入口，禁清库重建 |
| 边界 | 仅H3视频，实际文本模型与配置一致，ports CE闭合 | 不可用provider给明确原因，不静默换模型 |

测试建议分层：纯validators/编译器 → repository/迁移 → API契约 → workflow故障注入 → frontend状态与参数 → Playwright真实UI → 有预算的小样真实模型。先跑离线反例，失败时不再花钱试同路径。

## 4. UI与操作体验的可测标准

2026-09-27审核修订：数值、视口、评分尺度、样本层级和阶段依赖唯一配置为[acceptance-policy.json](acceptance-policy.json)。本文解释合同；总案/专项只能引用，不再自定容差。旧报告按当时policy保留，禁止重算或换门槛将历史FAIL洗成PASS。该配置是我方验收设计I，不是LibTV承诺；本轮未执行产品验收。

### 4.1 页面与状态

冻结源站已取证的UI-01–UI-10参考屏及新增FP证据，原图仅本机留存。采用policy规定的同视口、浏览器缩放、DPR、字体/浏览器/OS、同内容与同画布缩放。动态双方捕获同一稳定状态；无法匹配则标not_comparable，不能仅冻结本地。隐私原图留受控目录，公开脱敏图不是像素门输入。照片只核功能，不测精确几何。

必截状态：空画布/已有节点；浮窗/停靠；Top8开/关；主题材/融合/互斥禁用；参数卡打开/关闭/校验错误；原创/改编/导演/全能菜单；上传中/失败/完成；输入引用；方向/费用/定稿问卷；编辑器普通/选区/单处diff/多组diff/冲突；历史空/搜索/重命名；Skill创建/编辑/自测失败；批量部分成功；重连/UNKNOWN。未知源站状态用我方基准并标I，N补证后再校准。

### 4.2 唯一视觉门（参数读取policy.visual）

- 主/回归视口、关键边界/按钮/间距/圆角/字号容差读取policy.visual。源图画布缩放不同时重新捕获，不后处理对齐；Windows另用真实浏览器，不用Mac窄屏代替。
- 沿现有`tests/director/pixel_compare.py`：原尺寸RGB，单像素最大通道绝对差超过rgbChannelThreshold计变化，changedPixels/全页像素数与maxFullFrameChangedRatio比较。不得resize/blur/mask/自动平移过门；区域指标仅诊断，另以DOM关键几何和人工逐项核查防止全页平均掩盖局部错误。授权不明图标/图片用自有资源时登记明确差异，不宣称严格全页等价。
- 文本截断、菜单遮挡、水平溢出、焦点丢失、IME误发送、不可解释禁用均为0。Tab/ShiftTab/Enter/Esc/保存快捷键可走完关键流程；弹层关后焦点回触发器。
- 正常路径不能增加没有决策价值的确认卡；确认计数以方向、总纲、逐集定稿、必要费用门为基线，额外来源歧义/容量/权限确认必须有可见原因。默认不弹episode-plan确认。
- 在固定本地基准机和500节点/100集文档样例记录浏览器/硬件/数据hash；本地按钮反馈p95≤200ms、编辑按键反馈p95≤100ms、从缓存切文档p95≤500ms。网络/模型耗时另报，不用本地指标掩盖生成慢。刷新恢复CP在服务端可达时p95≤3s（30次采样）。这些是目标，未测不能写已达。
- 源站375px等宽度的控件可达性已有局部证据，但全站移动视觉组合未完整测；自有设计至少320px宽无不可访问关键按钮。局部证据不外推为手机1:1复刻（U04）。

每屏按policy.visual.states填写适用矩阵：stateId、requirementIds、viewports、fixtureHash、sourceCaptureRef、localCaptureRef、DOM测量、操作用例、比较报告、status。N/A必须说明原因；缺截图/未取证为not_run/unknown，不算通过。先完成该切片所有适用状态再升级视觉状态，S10只做全量汇总回归，不将视觉工作全部后置。

## 5. 内容质量对标：不靠同一个模型自夸

### 5.1 样本和控制变量

数值与模型读取policy.modelPolicy/literary。当前仅本地`doubao-seed-evolving`对源站Seed；同名不保证服务端采样/隐藏指令相同，未知明确记录。分三层验收，不互相替代：

1. S1先用stageProbes.A《入画》，同源概要或原文必须两边一致且固定hash/已确认规格；方向、大纲首稿、同一句修改和恢复分别配对。模型初稿与修订稿都保留。阶段门逐维达到medianMinimumPerDimension，单对差达到pairedMinimumMeanDelta，关键事实全过；只有单评审时标provisional_not_full_parity，可以继续开发但不授予全产品质量通过。
2. S2–S4依次加入stageProbes.B/C/D作保持集；改技能后复验原负例及受影响保持集。A–D为过程探针，不是完整产品分母。能够证明输入/配置/阶段一致的既有证据可复用，无需重复付费。
3. S10按下方B01–B12执行fullGroups/runsPerFullGroupPerSide，全量样本数由policy冻结。A–D若严格满足某B组可按runId去重纳入，缺失再补；不能把不同输入/模型/时长拼成胜率或用四组代替全量。

| 样本组 | 类型 | 重点 |
|---|---|---|
| B01 | 1×30秒闭合原创 | 极短容量、末集收束 |
| B02 | 2×30秒原创 | 续写、前后边界、逐集审批 |
| B03 | 3×60秒温情/喜剧 | 非爽剧不强造反派、角色语气 |
| B04 | 6×60秒悬疑 | 揭示顺序、跨集兑现、长上下文 |
| B05 | 来源短篇浓缩 | 保真与合理删减 |
| B06 | 同源扩写 | 新增桥段因果与来源标注 |
| B07 | 同源强化冲突 | 动机、代价、行动，非降智 |
| B08 | 同源强化钩子 | 本集结果、悬念与兑现 |
| B09 | 长稿跨块与别名 | 完整阅读、独立漏检 |
| B10 | 已完稿跨集调整集数/风格 | 不漂移事实、部分采纳与回滚 |
| B11 | 英语/海外转换 | 语用和格式，文化与硬事实分离 |
| B12 | 用户限制严格的单集改编 | EP02语义反例、动作可拍、试读计时 |

历史V3.2/V4-Flash比较仅保留原报告，不是本轮执行要求；新增模型横测须用户重新要求，不静默切换或双模型并跑。若供应商不支持随机seed，不假装确定性。API异常作为传输失败统计，不填文学0分（0不属于评分尺度）；同时披露失败率/费用，不能只挑成功样本。

### 5.2 评分与通过阈值

先做硬约束：全部样本关键来源事实/编号/受保护对白/用户禁项错误为0；可测时长预算和动作资源无已证实超量；不确定处全部显式标记且不能伪测量。任一关键FAIL未修正，不能用平均质量掩盖。

全量匿名打乱来源，由policy要求的独立人工评审人数按同一scale/dimensions评分；至少一名不是该稿生成操作者。锚点：1=关键不可用，2=多处实质问题，3=需重写主要场次，4=少量局部修改可用，5=无需结构修订。差异达到reviewerDisagreementForArbitration时讨论原句证据或第三人仲裁，保留原分。Seed只能辅助审稿；没有足够独立评审则完整质量门为not_run，不能模拟评审身份。

全量阈值读取policy.literary：每维总体中位数、配对均分差合格比例、首次稿结构重写比例均需满足；关键事实任何失败不得被均值抵消。修复后复跑原负例及相邻集；记录人工改动时间/范围、调用次数/费用。该样本规模仅支持描述性验收，不证明所有题材完全相同或更优。没有配对结果只能说本方标准通过，不能说源站等价。

时长实测至少覆盖B01/B02/B12：台词试读与动作分镜分别计时，合并声画时间线；30秒目标的最终预演落在项目约定容差内（此基准采用±5%，超差需改稿或用户改规格）。其他样本估算区间与证据如实列出；未排演不标成片Ready。批评不能只写“模型问题”，每失败追到规则/上下文/输入/阶段/校验/模型能力之一，并生成回归fixture。
