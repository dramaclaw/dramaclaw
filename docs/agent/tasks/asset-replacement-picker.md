**状态**：待验收

## 目标

让用户既能把节点拖到素材库替换目标素材，也能在侧栏收起时点击节点入口或右键节点进入
“挑选态”，随后选择同类型素材并经确认完成替换。

## 非目标

- 不改变替换请求的服务端协议、主线素材业务规则或 LibTV 本地化流程。
- 不顺手合入画布 LOD、模型设置、项目入口等相邻工作树改动。

## 现状与证据

- 现有拖拽入口要求一次性拖到左侧素材库；素材库默认收起，点击入口没有可靠落点。
- 工作树新增 `pendingPick` 状态、Esc 退出、同类型筛选、右键节点入口及 4 个三语提示键。
- 聚焦回归测试 `asset-replace-pick.test.tsx` 已随工作树存在，覆盖点选替换与不匹配素材。

## 协调与冲突

- `Canvas.tsx` 与 `AssetCommitHandle.tsx` 分别和 LOD 共享；只提交替换 hunk。
- 资产库与外壳同 LibTV 导入线共享；导入/本地化 hunk 已独立提交，本线不重写。
- locale 是共享键空间，三种语言同时提交并过 i18n 棘轮。

## 风险与回退

- **风险**：挑选态残留会让素材库普通点击被误解为替换；状态机必须在确认、取消、Esc 和新拖拽时互斥清除。
- **回退**：单独撤销本工作线提交即可恢复纯拖拽入口，不触碰 LOD 与 LibTV 导入提交。

## 已定下来的决策

- **点选与拖拽共用同一个确认请求**——两种入口只改变“怎么选目标”，不复制替换后端逻辑。
- **挑选态仅高亮同类型的可替换素材**——避免点击时意外执行“添加到画布”。
