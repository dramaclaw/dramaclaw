## 目标

研究完整 TV Director（全能、原创、改编、导演执导、Skill 生命周期、附件/引用、设置、历史及画布工具），用户剧本与默认入口作为起点。交付按钮级功能报告及细化到功能逻辑、数据合同、代码落点和验收用例的全新系统开发方案。明确实证与推断边界，可直接作为后续实现依据。

## 非目标

- 本轮不修改业务代码，不把前端观察冒充已获取服务端私有 Skill / 系统提示词。
- 不改动用户已完成剧本，不复制凭据、签名媒体地址或第三方完整剧本到仓库。仅运行合成研究样例；本续轮两集正文各30积分，用户另明确批准一次70积分H3测试，总批准上限130积分。H3用于参数与断线恢复同任务验证，失败不自动重试、不重复扣费，不生成其他媒体。

## 现状与证据

- Git 基线见上；工作区仅有三类受保护未跟踪资料，拟改路径无既有 diff。
- `story-writer` 已实现四阶段写作、通用 JSON 文档持久化和前端路由；本轮只读复用评估。

- 本地相关远端分支没有 story/director 同名实现；拟新增两份报告与本地 `origin/main` 比较无路径重叠，未执行远端同步。
