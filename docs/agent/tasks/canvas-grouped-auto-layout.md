## 目标

整理画布时，把分组内子节点的跨组连线纳入顶层布局，使源素材保持在下游组左侧；将用户本地 LibTV 导入画布的顶层位置和视口恢复到整理前的状态，保留之后的内容、连线和组内编辑。

## 非目标

- 不修改文本引用卡片、生成参数或远端 LibTV 画布。

## 现状与证据

- 本地画布 rev33 的 14 个顶层坐标与 LibTV 原画布相同；rev34 一次移动全部 14 个顶层节点，结果与现有 `computeAutoLayout` 完全吻合。
- 现有布局只保留两个端点都是顶层节点的边；该画布 88 条边均被丢弃，素材与分组被当成独立组件打包。
- 当前 rev46 已有后续组内位置和边的编辑，因此仅恢复顶层节点的 `position` 和画布 `viewport`，并通过画布存储接口建立历史快照。rev33 视口为缩放 0.1；rev46 为 0.218，若仅恢复坐标仍看不到参考图的整体布局。
- `git status` 已核对，目标代码无旧 diff；`origin/main` 对目标文件没有相对当前分支的差异。其他工作线未认领两个目标代码文件。
