## 实施方案
1. 活动队列结束后按 job ID 查询状态/成品；队列 completed 无内嵌输出也走同一查询。兼容无单任务接口的工作台时，仅按精确 job ID 从作品库认领，删除 mode/最新文件猜测。
2. 短暂网络失败保留同一个任务 ID，间隔补查不重新提交；明确失败/取消仍返回失败。完成下载后走既有任务持久化和 SSE 通知；不使用不存在的 workbench events 路由。
3. 本次失败记录和画布先备份，以任务 ID、提交时间和实际提示词/参数确认匹配，下载已完成视频；按既有 TaskManager 完成接口恢复原任务（校验旧 task_id），清错误；画布 revision 条件保存新视频结果。
4. 静态语法/ruff 检查与真实已有任务只读查证、成品接回，不提交新生成任务。本轮未请求测试，不增加/运行测试。
5. 无活跃任务时重启本地 API 使改动生效，保留 ComfyUI/H3 工作台运行。

无 job ID 的作品不猜测归属；网络异常不触发重复 POST。恢复使用备份、任务运行 ID 和画布 revision 防止覆盖较新生成或用户编辑。回退只还原本线增量和定向备份。
