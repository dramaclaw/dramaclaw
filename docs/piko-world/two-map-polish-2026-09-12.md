# 双图样板收口 — 2026-09-12

## 本轮调整

- 小狗显示专名“罐头”，小猫显示专名“小月亮”；与居民共用 Pixi 名称样式，随动物移动及场景遮挡，不增加点击区域。
- 名字固定在脚底坐标以上，不随序列帧透明留白抖动；小猫名字位于桃心最高位置之上。
- 镇长以 DOM 名称代替闪烁问号，保留原交谈按钮、悬停及键盘操作。名称不因完成欢迎对话永久消失，加载或对话期间仍按原页面阶段隐藏。
- 所有地面角色和动物复用 `createContactShadow` 的三层像素接触阴影。动物保留原投影外框，蝴蝶保留较小、较淡的脚下投影；身体升降不带动地面投影。
- 十九只动物只生成一张 24×8 阴影纹理并共用，运行时销毁后释放；不增加图集请求或逐帧纹理生成。
- 更正总规划中“尚未接入角色和碰撞”的早期进度描述。

## 性能与声音的代码检查

这是静态实现与自动化生命周期检查，不是 GPU/FPS、内存峰值或主观听感实测。

- 动物使用十张 2048×2048 动作图集，共享帧纹理；仅动作图集按 RGBA8 计算为 160 MiB，未包含桃心、底图、遮挡、人物、渲染目标和驱动开销，不能当作实际显存总量。
- 新阴影原始像素为 768 字节（24×8×4），实际 GPU 分配另有开销。名字只创建两份，不在每帧重建。
- 动物共享一个 ticker 回调；后台和减少动态模式会解除该回调。地图实例退出清理纹理、ticker、监听和音频；相关回归覆盖旧实例迟到、替换实例资源持有与反复销毁。
- 渲染分辨率上限为设备像素比 2；尚无本轮真实帧率或长时间运行占用数据。
- 动物叫声使用距离衰减，同一时刻最多一路，结束后至少留白 5 秒；各物种另有 20–75 秒范围内的冷却配置。
- 环境音独立按区域衰减，离开区域渐弱，后台暂停；共用 BGM 跨双图连续播放。BGM、环境音、脚步和动物音之间尚无统一混音预算，当前不自动修改用户已确认的音量。
