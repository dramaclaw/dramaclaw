# 角色头顶任务标签

2026-09-18 确认。目标：用户离开工作台进入小镇后，仍能了解任务是否进行或结束，并返回对应创作位置；同地图玩家可看到创作活动与完成状态。

## 展示与点击

| 任务状态 | 本人 | 同地图其他玩家 |
| --- | --- | --- |
| 等待或执行 | 任务进行中 › | 作品创作中 |
| 完成 | 任务完成 › | 任务完成 |
| 失败 | 任务失败 › | 不显示 |
| 无任务或主动取消 | 不显示 | 不显示 |

不显示省略号、百分比、任务数或额外社交状态。本人整块标签可点击，右箭头由代码绘制；他人标签无箭头且不可点击。

点击按任务来源返回对应项目、画布或分集，支持时定位节点。来源需要与任务关联，不能通过浏览器后退实现。目标已删除或权限失效时明确提示并提供工作台入口，不自动重试任务。

多任务时有进行中任务优先显示进行中；跳转优先选择进入小镇前关联的进行中任务，否则选择最近发起的进行中任务。全部结束后，本轮未查看结果有失败则优先失败，否则展示最近完成结果；取消不归为失败。本轮由进入时进行中的任务以及停留期间新发起的任务构成，包含这批任务结束后的未读结果，不重新引入任意历史任务。

## 显示周期

- 新任务、进入小镇时已有任务、完成或失败：立即显示。状态变更打断隐藏等待；可见时直接换文案并重新完整展示 5 秒。
- 每15000ms开始一轮：淡入250ms，完整展示5000ms，淡出250ms，完全隐藏9500ms。减少动态效果时展示5000ms、隐藏10000ms，周期保持15000ms。
- 本人未查看的完成/失败结果继续循环，点击查看或新任务开始后结束。点击进行中标签只是导航，不永久屏蔽后续状态。
- 他人完成状态自服务端确认的完成时间起有效 60 秒，在有效期内循环；过期即收起，新任务优先。本人是否点击不影响公开完成期限。
- 本人鼠标悬停或键盘聚焦时暂停淡出，离开后继续；隐藏时不可点击、不可聚焦，不能挡住地图操作。点击可见标签不触发走路。
- 切图保留周期；页面恢复时根据当前时间与最新状态恢复，不补播错过的轮次。账号变化清理原账号状态和计时。
- 暂时断网不判失败，不用虚构进度；保留最后确认的本人状态并在恢复后校正。公开状态依赖在线成员与服务端过期规则。

## 素材与位置

用户生成并抠图，提供单张完整空白底板；由项目切成左、中、右三段，中间横向拉伸。奶油纸面与浅木细边框，宽高比约 4.5:1，中间至少 60% 保持平整、无花纹。原图背景为纯白色 #FFFFFF，便于抠图；无文字、箭头、图标、尖尾与外部投影。所有状态共用底板，文字和箭头由代码绘制。

标签在昵称上方，保留帽子空间，聊天气泡显示时暂时隐藏任务标签，气泡靠近昵称，不为隐藏标签预留高度；靠近边缘时保持可见。具体尺寸以用户验收为准；项目不截图验收视觉，负责功能、可访问性、素材尺寸与代码检查。

## 数据边界与实现步骤

当前工作台任务订阅按项目运行，小镇独立于工作台布局；真实多人在线同步尚未接入。以下是目标契约，不代表现有后台已经提供。

1. 独立实现并测试状态选择、周期与公开字段筛选，不把模拟数据放入正式运行路径。
2. 用户提供底板后，切片并接入头顶组件、点击、布局与计时；将组件规格同步到 DESIGN.md，运行设计检查。
3. 接入本人任务适配层：按当前账号权限恢复任务、本轮范围、未读状态与来源；覆盖刷新、切图、重连和账号切换。来源不明时不能编造具体画布或节点位置。
4. 多人适配层仅接收服务端发布的同地图玩家公开状态：进行中/完成、状态版本、有效时间；不分发项目名、任务 ID、错误、提示词或本人跳转地址。需与真实在线成员系统联合接入与验证。
5. 功能测试涵盖并发任务、取消、完成打断等待、重复快照不重置周期、过期、悬停/焦点、隐藏命中、任务来源和账号隔离。用户验收前端视觉及交互。

跨设备未读恢复与多人公开状态需服务端支持；本机存储不能冒充这两项能力。


## 2026-09-18 当前实现进度

已接入本人路径，复用现有 `GET /api/v1/projects` 和项目级 `/tasks` 接口，不要求新后台接口即可跟踪服务端已有任务。请求按项目现有路由访问，最多3个并发；含本人进行中任务的项目每5秒查询，其余项目每30秒查询，每60秒重新发现有权限的项目。检测到状态变化立即打断标签等待，检测延迟取决于轮询和网络，并非已实现服务端推送。

工作台进入小镇前捕获当前项目任务、选中任务与画布关联；进入小镇页面后即开始追踪，开场和角色创建期间继续查询。任务按后端 `username` 筛选为本人，优先使用 `task_id` 区分重试轮次；不展示项目协作者的任务。记录按账号和地区隔离，仅在本机保存最小状态与来源，跨设备未读同步尚未实现。

导航使用任务 `metadata.canvas_id` 或既有分集/项目任务类型映射，点击前检查项目或画布是否可访问；未知来源回到该项目任务列表，不猜测画布，不承诺节点级定位。403/404移除无法访问的任务，网络失败保留最后确认的本人状态。隐藏标签不可聚焦、不可点击，切图保留计时，页面恢复不补播。

已接入用户提供的三段透明PNG，显示高26px、字号11px，左右端保持比例，仅中段拉伸；没有截图验收或触发真实付费生成。公开状态投影函数与60秒期限已定义并测试，但没有向本地模拟居民添加假任务，真实多人广播仍待在线成员后台对接。
