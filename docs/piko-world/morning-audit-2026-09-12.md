## 已修复

| 问题 | 原因与处理 | 回归证据 |
| --- | --- | --- |
| 黑场可能无限等待 | 预检无截止时间、Canvas加载无截止时间；分别增加15秒、30秒期限，中止旧实例并暴露恢复入口 | 卡住预检/Canvas、超时后迟到响应、卸载取消测试 |
| 淡黑时长随网络波动 | 同一个effect依赖准备结果，数据返回会清除并重设动画计时；拆分计时与换图effect | 200ms返回数据后仍在总计300ms时换图 |
| 准备失败后原地图标题重播 | 通过伪造loading状态暂停标题，恢复ready再次启动计时；改为显式paused并记录本次标题是否完成 | 超时返回源图不重播标题，成功切图仍完整展示 |
| 同图重试可能误卸载新实例纹理 | 只有人物/箭头采用引用计数，其他运行时直接卸载共享URL；全部使用同一纹理持有/释放机制 | 旧动物实例晚到清理不会卸载新实例；加载和卸载失败后仍可重试 |
| 错误/加载提示使用原图名称 | 切图准备阶段location仍指向原图；独立记录本次目标 | 准备失败显示匠作市集名称 |
| 重试与返回逻辑分散 | 合并为reloadMap，同步设置请求锁；travelPending改由阶段推导，删除冗余状态 | 失败返回、重复触发、卸载清理测试 |
| 空对象数组风险重复存在 | 全部改为逐个挂载；空效果集合不会调用addChild | 既有空市集环境与运行时回归 |
| 文档含旧版本和重复实现描述 | 地图连接文档改为当前状态，庭院revision统一为50；测试与审计结果集中在本文件 | 文档与manifest核对 |

## 保留并确认

- 庭院与市集双向安全落点在触发区外，可寻路至出口和地图中央。
- 篱笆使用细长碰撞体，西侧道路保持通行，小狗从南端绕行；碰撞与动物整段路线回归通过。
- 箭头继续使用用户确认的原图集、地面层、尺度与目的地文字。
- 正常切图保持淡黑300ms、淡入400ms，之后地图名停留1200ms、淡出1000ms。
- 共用BGM不因切图重启；退出整个世界时原有800ms音量渐隐保留。
- 对manifest所引用的底图/数据文件进行了存在性核对；箭头图集为2048×1024；三种语言的恢复操作键一致。
