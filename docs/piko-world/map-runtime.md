场景音由各图 `data/environment.json` 配置，同类声区合用音轨。市集有全图间歇鸟鸣、9 处虫鸣区域及7 处树群风声区域，工作台周围不叠虫鸣与风声；灯河街以河流声覆盖上下游，右下浅滩使用单独的海浪声，风声和虫鸣分布于两岸林冠、草丛。母鸡、牛、猫、狗共用按物种配置的距离衰减、冷却和互斥规则，五张地图不再使用单图音效增强。兔子、松鼠、蝴蝶不配置叫声。灯河街桥上西侧两灯、东侧一灯共用庭院灯光粒子机制。

云顶坡是开阔山脊与云海，云雾分顶部、中部坡地与下部前景三条路线同向水平经过，飞鸟沿三层天空通过；草坡和花丛分散放置 2 头小牛、3 只兔子、3 只蝴蝶。全图有山风和稀疏鸟鸣，虫鸣只在低处避风的花草区。琥珀原野是暖色麦草与开阔道路，云雾和飞鸟停留在上半部天空；道路两侧分散放置 3 头小牛、4 只兔子、3 只蝴蝶。全图有草原风声和间歇鸟鸣，虫鸣集中在路边草丛与遗迹周围。两图复用庭院天空图集、动物图集和音源；环境音文件放在各自地图包内。

灯河街三段水面共用庭院 4×4 河水图集，以 2fps、30%／30%／20% 不透明度和第 0／5／10 帧起播。遮罩覆盖温室侧河沿、上游东岸、桥前以及下游两侧可见河水，避开桥面和露出水面的岸石；浅滩保留底图细节。7 条鱼分属上游、下游和浅滩，以水域 ID 绑定路线，数量、摆尾与避让说明见 [河流鱼群](river-fish.md)。页面隐藏时暂停，减少动态效果时保留静帧；离开地图释放资源与回调。

云顶坡崖外云海的额外叠加样片已撤除。现有薄云分三条水平路线：顶部y=80，中部y=520，下部y=900；中下部从x=-500至2548横穿，用64–96秒覆盖完整行程。三片独立计时、错相显示，宽度保持1.75倍、共用云片与投影透明度和微弱上下浮动；中下部重生等待3–6秒，高处12–20秒，进出各14%渐隐。具体参数见 `DESIGN.md`。环境声在取得角色实际位置后开始调度，并沿用入图前的用户操作解锁；浏览器拒绝播放时等待后续操作重试。

琥珀原野共12簇草丛动态点缀，沿中上部缓坡、遗迹外侧和右侧开阔草地疏密分布，共用8帧金黄草丛图集、2fps错相循环；不替换底图大面积草地。位置、素材来源与生成提示词见 [草丛动态](amber-grass-breeze-v1.md)。

## 市集长椅交互

左右两把长椅均可悬停提示、点击自动寻路并落座，沿用庭院男女高清坐姿与4秒眨眼周期。点击地面或方向键从椅前站位起身。西侧站位避开石头，东侧仅在坐姿时使用独立显示深度以保持头脸可见。交互命中区在 `artisan-market/data/interactions.json`，落座点、站位及显示深度在 `runtime/seat-actions.ts`；无须新增角色素材或改变地图碰撞。
