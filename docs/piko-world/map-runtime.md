匠作市集与灯河街复用初遇庭院的云雾、飞鸟贴图和运行机制，在 `map-aerial-runtime.ts` 分别配置屋顶、中央道路或河道、南侧林缘路线。动物共用庭院图集；灯河街有 4 只母鸡、3 只兔子、3 只松鼠，并保留跨图巡游狗，落地动物避开水域、桥面和北侧入口。

场景音由各图 `data/environment.json` 配置，同类声区合用音轨。市集有全图间歇鸟鸣、9 处虫鸣区域及7 处树群风声区域，工作台周围不叠虫鸣与风声；灯河街以河流声覆盖上下游，右下浅滩使用单独的海浪声，风声和虫鸣分布于两岸林冠、草丛。母鸡与狗的叫声随动物位置播放，灯河街母鸡使用更短的叫声间隔和较宽的听觉范围。灯河街桥上西侧两灯、东侧一灯共用庭院灯光粒子机制。

云顶坡是开阔山脊与云海，云雾横过高处、中部和崖边，飞鸟沿三层天空通过；草坡和花丛分散放置 2 头小牛、3 只兔子、3 只蝴蝶。全图有山风和稀疏鸟鸣，虫鸣只在低处避风的花草区。琥珀原野是暖色麦草与开阔道路，较淡的云雾和飞鸟停留在上半部天空；道路两侧分散放置 3 头小牛、4 只兔子、3 只蝴蝶。全图有草原风声和间歇鸟鸣，虫鸣集中在路边草丛与遗迹周围。两图复用庭院天空图集、动物图集和音源；环境音文件放在各自地图包内。

灯河街三段水面共用庭院 4×4 河水图集，以 2fps、30%／30%／20% 不透明度和第 0／5／10 帧起播。遮罩覆盖温室侧河沿、上游东岸、桥前以及下游两侧可见河水，避开桥面和露出水面的岸石；浅滩保留底图细节。7 条鱼分属上游、下游和浅滩，以水域 ID 绑定路线，数量、摆尾与避让说明见 [河流鱼群](river-fish.md)。页面隐藏时暂停，减少动态效果时保留静帧；离开地图释放资源与回调。

云顶坡崖外云海的额外叠加样片已撤除；放大现有云层、提高出现频率的方案尚未实施。环境声在取得角色实际位置后开始调度，并沿用入图前的用户操作解锁；浏览器拒绝播放时等待后续操作重试。
