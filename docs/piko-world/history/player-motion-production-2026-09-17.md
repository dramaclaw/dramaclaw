# 玩家角色四方向行走制作（2026-09-17）

本记录补充 [Piko 像素制作规范](../default-piko-pixel-production-spec.md)。本轮由项目调用 imagegen 生成候选，用户负责抠图和视觉交互验收；项目负责帧规范化、图集合成、运行时接入和技术检查。先完成男性，男性效果满意后沿用相同帧网格和轴心制作女性。

当前地图中男性使用 `player-male-motion-v2.png`，女性使用 `player-female-motion-v3.png`。下文旧版本的源图与检查数据保留作历史对照。

用户确认女性沿用男性的图片缩放方式。女性 v3 恢复 64×64 单帧、56px 可见高度、最近邻缩图与采样、二值透明及 `(32,57)` 脚底轴心。左右待机采用此前 imagegen 根据四方向母稿重做的 v3 源图；归一化后的头宽分别为 21/21px、22/22px，行走头宽为 22–23px、21–23px。构建脚本对侧向待机与行走头宽差增加不超过 2px 的检查，避免只验证总身高而遗漏头身比例。

侧向行走不再按两排素材顺序各重复一次同向摆臂，而按 `v2:0 → v2:1 → v1:2 → v2:2 → v2:5 → v2:4 → v1:5 → v2:3` 编成一个完整前后摆臂周期；其中 v1 的两帧提供双腿经过身体下方的姿态，v2 提供相反的摆臂姿态。每个源姿态仍来自完整人物图片，没有单独拉伸、旋转或拼接肢体。步速、按路程推进的步态和 8 秒待机周期沿用已有设置。此编排改善重复摆臂和缺少收腿过渡，源图对近远腿的区分仍有限，连续走动观感需实机验收。

## 女性角色动作接入

放大核对图与各方向像素宽度记录在 `piko-world/art/review/player-female-motion-v1/`。44 帧均通过 64×64 尺寸、二值透明和脚底线检查。前端定向测试 8 项通过，生产构建通过，预览服务对女性图集返回 HTTP 200。实机观感仍需在地图内验收。

用户后续反馈正面待机眼睛缩小后异常、左行手臂不动、右行摆臂节奏不自然。v2 采用 imagegen 依据原透明素材修订的正面待机与左右六帧行走图，源图分别为 `player-female-south-idle-keys-v2.png`、`player-female-west-walk-keys-v2.png`、`player-female-east-walk-keys-v2.png`；向上和向下行走及两侧待机保留原素材。构建时对女性帧使用 BOX 面积缩小以减少眼睛细节在 56px 上的孤立黑点，仍保持 56px 高、同一脚底线和二值透明。新图集为 `player-female-motion-v2.png`，放大检查图为 `player-female-motion-v2-inspection.png`。v2 侧向摆臂较 v1 明显，实际步臂配合仍需地图内连续行走验收。

玩家待机节奏已从 4.8 秒两次动作放缓为 8 秒两次动作，时间轴 `0→1→0→1→0` 各段为 2200/350/3500/350/1600ms。男、女玩家使用相同节奏；居民仍用原 4.8 秒周期。

## 帧协议与生成

执行 `.venv/bin/python scripts/build_piko_player_walk.py`，从源图确定性构建 `frontend/public/piko/world/characters/player-male-motion-v1.png`。脚本逐帧验证尺寸、二值透明和脚底线。游戏帧为 64×64；图集为 704×256，方向按 `south / west / east / north` 排行，每行前三列待机、后八列行走。脚底轴心 `(32,57)`；八相位按六张源姿态 `0,1,2,2,3,4,5,5` 排列，两个过渡姿态各保持一拍，不伪造关节画面。接触阴影独立绘制，最近邻采样和地图现有距离驱动步态保持不变。

评审预览与元数据在 `piko-world/art/review/player-male-motion-v1/`。未来服饰与配饰必须采用相同画布、方向、帧序和轴心，并记录肩、手、腰、髋及遮挡关系。当前图集是完整基础服饰，不宣称已完成可替换衣装图层。

## 2026-09-17 地图视觉反馈与下一轮素材

用户实机指出：左右行走的甩腿幅度过大；向下行走的身体显得扭捏、双臂摆动不足；待机没有动作。当前三列待机帧只是同一四方向站姿的副本，不能称为已完成的待机动画。此轮男角色动作尚未通过视觉验收，女性角色暂不复制这套动作。

下一轮沿用已确认的四方向母帧作为唯一造型依据，替换左、右、下三张六姿态行走源图，并新增四方向三姿态待机源图。上行走暂保留，等实机复查时再决定是否调整。行走源图仍为每张 3 列×2 行，姿态顺序和源文件命名保持不变；待机图为 3 列×4 行，行顺序 `south / west / east / north`。每个方向的待机三帧依次为自然站立、轻微吸气或眼神变化、自然呼气或眨眼；脚底、髋部、肩宽和人物水平位置稳定。待机不得用整个人的缩放或平移代替身体动作。所有新帧最终仍须满足 64×64、二值透明、脚底 `y=57`、图集 11 列×4 行及可换装挂点协议。

左右行走的新关键姿态应收小前后脚距离，保持完整的膝、脚踝和鞋轮廓，并让手臂与腿自然反向摆动；不要出现踢腿、后腿向后甩飞或头身前后摆动。向下行走应保持头、肩、胸、髋朝正面，肩膀水平，双臂从肩和肘处自然反向摆动，手与躯干有清晰间隙，腿部交替承重；不要靠扭转整个躯干或贴身手臂制造动作。每组新图先裁切预览并由用户验收，再替换地图图集。

### 待机比例与节奏修正

实机反馈待机形体较行走偏宽，并在约一秒内出现两次抖肩。v2 初版虽统一为 56px 高，待机中性帧宽 22–26px，行走经过帧约 20–21px。构建脚本现按每方向的中性待机帧统一水平缩放该方向的三帧，使中性帧宽 21px；肩臂展开帧可比中性帧宽 1–3px，保留动作轮廓。脚底线和高度不变。待机时间轴改为 `0→1→2→0`：中性站立 1800ms、缓慢抬肩 1300ms、放松 1700ms，每 4800ms 只做一次完整动作，停止行走后从中性帧开始。

后续视觉反馈指出第 2 张动作姿态有横向压变形。运行时待机现只采用中性姿态 0 和抬臂姿态 1；图集第 2 列复制中性帧以保持 11 列协议，不再使用原第 2 张姿态。时间轴为 `0→1→0→1→0`，各段 1300/550/1300/550/1100ms，完整循环 4800ms；两次抬臂间隔超过一秒。

行走验收反馈帧切换过快且位移显飘。男角色移动速度从共用的 150 地图像素/秒降至 135 地图像素/秒，一整步周期从 `40×角色缩放` 调至 `48×角色缩放` 地图像素；八相位播放从约 15.6 帧/秒降至约 11.5 帧/秒。完整横穿 2048 像素地图的理论时间从 13.7 秒增至 15.2 秒；障碍、通道和交互会使实际路线更长。女性角色接入后沿用这一玩家步速和步距；居民与其他角色继续使用原速度和步距。步态仍由实际移动距离推进，碰撞停住时不继续迈步。

### 静止与行走比例复核

四方向的待机与行走帧均为 64×64、可见高度 56px，共用同一个运行时 `body.scale` 和脚底轴心；移动时没有额外缩放。按图集像素测量中性待机帧与行走经过帧：正面头宽 19px 对 19–20px、躯干轮廓 21px 对 20–21px；左右侧头宽 21px 对 20px、躯干轮廓 11–12px 对 11px；背面头宽 19px 对约 17px、躯干轮廓均约 21px。正背面站姿双腿分开，腿部轮廓宽约 17px，行走经过帧双腿重叠约 11px，这会产生视觉上的宽窄切换，但不是整个人物的缩放。背面头部还有约 2px 的素材比例差异，后续若实机仍显突兀，应修正背面待机源图，而不是再对整张帧施加非等比压缩。
