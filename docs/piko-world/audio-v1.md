# Piko 音效首轮接入

来源：用户提供的桌面文件。原件未修改。授权条款尚未提供，不从文件名推断许可；发布前应补齐来源许可记录。

## 文件分析与裁切

以下为ffprobe及静音/电平检测结果，不是听感验收结论。

| 输入 | 实测 | 选段 |
| --- | --- | --- |
| 按钮点击.mp4 | 容器2.96s；AAC音轨0.152s，解码含尾部约0.163s；峰值-1.1dB | 0–0.162s，提取音轨，不包含视频 |
| dragon-studio-button-press-382713.mp3 | 0.575s；-35dB阈值下0.094–0.235s及0.268s后低电平 | 0–0.290s，保留两次瞬态及少量尾音 |
| freesound_community-footsteps-in-grass-and-picking-82739.mp3 | 10.488s；24kHz；多个分离声音事件 | 候选0.99–1.27s、2.29–2.57s、4.32–4.60s |

按钮导出为44.1kHz单声道16bit WAV，开头2ms/结尾12ms淡化，避免硬切爆音。
打开音播放音量0.45，关闭0.60；未作激进增益或降噪。音量与尾音长度仍需实际试听。

## 接入范围

- 游戏入口、镇长交谈、欢迎翻页、聊天和居民设置打开：open。
- 对话关闭/完成、聊天关闭、设置关闭（含Escape）：close。
- 加载失败重试：open；返回工作台：close。
- 限游戏组件；不影响工作台按钮，无hover音效，无自动加载完成音。
- 用户操作时触发；复用音频实例、重复点击重置，避免声音堆叠；播放被浏览器拒绝不影响操作。

用户确认开始接入后，三个0.28秒片段已复制到运行时音频目录；试听副本仍保留于`piko-world/art/review/audio-v1/`。
按统一步态0/4接触相位触发，实际位移不足不触发；首次迈步触发一次，后续每半周期一次。
Web Audio在移动按键操作时解锁，加载未完成时跳过该步，不延迟补播；不连续重复同一片段，不改音高，增益0.7。
脚步与UI音独立，最多两个短音重叠。停止、撞墙、失焦时停止；角色销毁时取消请求并关闭音频上下文。
未通过自动化测试判断音色是否合适，最终听感（包括是否混入采摘声）仍由用户在游戏中验收。

重建：`.venv/bin/python scripts/build_piko_audio.py`。
