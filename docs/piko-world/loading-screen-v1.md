黑场衔接：满格停留 1.5 秒 → 250ms 全屏淡至黑 → 黑场中挂载地图名画面并保持 100ms → 350ms 淡入地图名画面。全屏黑幕与全屏标题蒙版独立，黑幕位于标题蒙版上方；场景切换在全黑时发生，期间禁用底层地图控件。卸载清理过渡计时器，减少动态效果设置下跳过淡入淡出，仅保留短暂黑场。

最新补充：进度到 100% 后保持 1.5 秒再自动进入，资源就绪与最少 3.5 秒展示条件不变。地图名采用原始尺寸缩小 20% 后的配置：桌面 33.6vw，上限 33.6rem，高度上限 24vh；全屏遮罩和黑场节奏不变，替代此前恢复原始尺寸及下文约三成的配置。

加载页不显示场景标题，只保留居中短句。进度条整图等比显示，可见宽度上限 440px、比例 1365:118，取消三段拉长，位置仍在底部居中。进入地图后的地图名过渡图缩小约三成，桌面宽度 30vw、上限 28rem，高度不超过 20vh。以下与本节冲突的旧布局描述不再生效。

## 全屏自动进入

- 加载页和地图标题蒙版作为地图 section 的兄弟节点，fixed inset-0 铺满视口，无圆角、无外围留白；地图本身仍保留原容器布局。
- 正常加载期间没有返回链接、进入按钮或其他操作。资源就绪与最低展示 3.5 秒须同时满足；进度完成后等待 250ms 收尾自动进入，不需要点击。
- 加载错误才显示常规返回工作台与重新加载按钮，不会自动进入错误地图。
- 下方 6% 水平安全边距、距底约 5dvh，左对齐显示场景标题、专属短句和横向长进度条。无状态胶囊；底部渐暗保证文字易读。
- 每个场景的中英文标题与短句见 translation.json 的 pikoWorld.loadingScenes，按场景 id 与背景绑定。
- 进度条两端采用位图三段显示，避免拉长花叶。按钮文件保留，但不再渲染或预加载。
- 不截图验收，视觉交给用户。

## 行为

- 每次进入或重试，从用户选定的 8 张图等概率选取一张；同次加载不轮播。随机允许连续两次相同。
- 只预加载本次选中的背景和三个控件，不下载其余七张背景。
- 图像准备完成并可展示后开始最少 3.5 秒计时。地图在底层同步初始化，控件与地图在进入前不可交互。
- 进度为展示动画而非网络字节百分比；真实地图未就绪时最高 90%。地图已完成首帧渲染且最少展示结束后到达 100%，启用带字按钮。
- 用户点击后才进入地图；保留既有地图标题过渡，过渡蒙版改为地图容器内绝对定位，不覆盖地图外的页面背景。
- 地图失败、加载素材失败或等待超时（30 秒阶段超时）进入错误状态，提供常规 UI“返回工作台”“重新加载”。加载过程中左上也可随时返回。
- 重试重建地图画布与加载页，取消旧加载页资源回调；重新随机背景并重新计时。卸载清理定时器与资源监听。
- reduced-motion 下关闭进度和按钮的 CSS 过渡，但不跳过最短展示时间。

## 素材与尺寸

运行素材：`frontend/public/piko/world/loading/`。背景清单见 `piko-loading.ts`，与用户最终保留的 8 张一致，低语草甸使用 v1。

外框和按钮使用用户自行抠图版本，填充使用已有 alpha 版本。原 PNG 不重绘、不裁切、不覆盖；显示时通过 SVG viewBox 仅呈现实际素材区域，以消除大面积透明留白。这些 SVG 只承载原位图，不替代原设计。

桌面进度条可见宽度上限 440px，按钮 232px；小视口按容器宽度缩小，整体位于地图画面下部。按钮文字直接来自图片，真实 button 仍提供可访问名称。

本轮只接入加载流程，不新增欢迎页、音效或背景音乐。没有截图验收，最终视觉由用户确认。没有提交或 push。
