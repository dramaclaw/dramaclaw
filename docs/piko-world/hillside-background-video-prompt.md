# 山坡背景图生视频提示词

使用 `frontend/public/piko/world/onboarding/welcome-hillside-v3.png` 原始纯背景图作为首帧，不要使用带角色、昵称或界面组件的截图。

## 正向提示词

以参考图为唯一场景依据，制作一段 8–10 秒、16:9、可无缝循环的治愈系像素插画游戏动态背景。镜头完全固定，保持原图的构图、透视、色彩、建筑、山脉和所有物体的位置与形状。温暖晴朗的山坡俯瞰宁静小镇，微风缓缓掠过草地，近处草叶和小花以很小幅度自然摇动，远处树冠轻轻摆动；河流与瀑布持续柔和流动，湖面出现细小而稳定的粼光；原有风车的叶片缓慢、平稳地转动，天空中的云仅作几乎不可察觉的缓慢变化。整体有安静、轻快、充满生命感的呼吸节奏。动态细腻克制，不抢角色创建界面的注意力。前景供角色站立的浅色石台、石径和脚下接触区域必须完全静止，右侧放置表单的草地区域动态尤其轻微。保持像素插画纹理稳定，边缘清晰，不闪烁、不形变。首尾画面自然衔接，风草运动回到相同相位，没有突变、淡入或淡出。无音频。

## 负向提示词

镜头移动、推拉、摇移、缩放、旋转、手持抖动、视差漂移、构图改变、石台漂移、地面起伏、建筑变形、树木融化、纹理闪烁、突然变光、昼夜变化、强风、暴雨、大幅摆动、密集粒子、夸张魔法光效、新增人物或动物、新增物体、文字、标题、UI、字幕、水印、声音。

生成后检查循环接缝与石台稳定性；提示词不能保证生成器严格实现无缝循环。
