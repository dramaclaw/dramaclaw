## 发现与修复

| 问题 | 修复与验证 |
| --- | --- |
| 单个环境声 play() 拒绝后将全局解锁状态设为 false，其他声道走出再进入时也可能等待新手势 | 改为每声道独立 blocked 状态；新手势重试该声道。新增回归测试确认其他声道仍可正常重新进入播放 |
| 音频 play() 尚在等待时玩家已离开区域，Promise 完成后仍可能短暂起播 | 完成回调重新检查当前区域增益，离区时立即暂停；补充异步回归测试 |
| 树冠每秒不到一次换帧，但动态剪影每个渲染帧都重新遍历轮廓、计算边界并序列化全部顶点 | 缓存动态轮廓，仅在 outline 引用改变时更新；遮罩缓存键改为局部版本号。现有站立人物动态遮挡测试通过 |
| 树存在时每帧检查说话气泡遮挡，移动时还会重复执行 | 改为人物位置变化或树冠轮廓换帧时检查一次 |
| 图集解码到一半出错时，前面已生成的 RGBA 纹理和画布没有集中释放；外层图形已先创建 | 解码失败销毁已创建纹理并清空所有临时画布；将图集解码前移至场景对象分配之前。补充第二帧失败的回归测试 |
| 图集仍在加载时就加入卸载集合，退出时可能对同一待加载资源重复安排释放 | 成功加载并确认未退出后再登记，退出回调单独释放晚到资源，与其他素材保持一致 |
| waterEffects 已同时包含水体、草丛等效果 | 统一命名为 environmentEffects |
| 旧树冠图集及已替换风声音源仍留在 public 中 | 确认无代码和地图数据引用后删除 east-tree-canopy-atlas-v1.png、leaves-v1.ogg，减少 4,193,578 字节（约 4 MiB）；历史文档及来源哈希保留，旧音源标记 retired |
