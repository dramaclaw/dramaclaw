# 罐头跨地图巡游

2026-09-16：巡游覆盖低语草甸、风庭门、匠人集市、初遇庭院、灯渠街、星灯码头。

罐头入场后直接开始一次外出，然后交替西行（集市→风庭门→草甸→原路返回）和东行（灯渠街→码头→原路返回）。每次回到庭院会再次走本地路线。普通节点休息60～90秒，庭院本地巡游和草甸休息90～140秒。休息前若45～75秒的狗吠冷却已结束，先原地播放一轮1.24秒狗吠动作，再趴下；不会边走边叫或睡着时叫。转角和桥面只通行，不休息。

`dog-world-routes.ts` 管理路线走廊和休息点。路段使用现有 A* 和逐段碰撞校验规划，运行时再次检查动物足迹；遮挡范围内不休息。切换地图必须到达真实出口，再使用出口指定的目标出生点。遇到新增碰撞阻挡会安全停住，并在控制器 `error` 中留下原因；不会跳过障碍或瞬移。

`dog-world-session.ts` 的单实例模拟由小镇 Shell 管理。玩家切图不会重置罐头，也不会创建第二个模拟；非当前地图不绘制它。页面隐藏或用户偏好减少动态时暂停，退出小镇释放计时器。当前为单用户会话模拟，尚非多人服务器权威状态。

侧向行走已按用户要求恢复最初的 dog-walk-v1.png 四帧，使用原始帧顺序、锚点和缩放；正常速度下每帧0.18秒，减速时按实际移动距离降低步频。上下行走、狗吠和休息继续使用已接入的动作。

验证：六图双向旅行、真实出口与出生点、各图休息、可走性、遮挡、单实例时钟、隐藏/减少动态暂停和渲染器不推进共享时钟均有测试覆盖。

诊断：控制器 `transitions` 保存最近20次真实地图转换及源出口位置，`error` 保存阻挡/路线错误。只有这条记录新增才表示真正进入另一张地图；走到建筑后方不代表跨图。
