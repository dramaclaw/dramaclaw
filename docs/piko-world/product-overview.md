# Piko 小镇产品说明

运营简版，更新于 2026 年 9 月 30 日。本文按当前项目实现整理，供介绍和体验策划使用，正式上线时间另行确认。

## 产品定位

Piko 小镇是平台内的休闲探索空间。用户在等待创作任务时，可以逛地图、听音乐、与小镇居民互动，收到任务状态提醒后返回创作。

当前最适合介绍的体验是场景探索、安静休憩和创作陪伴。真实多人社交仍待接入。

## 怎么进入

工作台右上角 **Piko Piko → Piko 小镇 New → 入场影片与邀请 → 选择男女角色、填写昵称 → 初遇庭院**。

入口右上角的红点在用户未点击时常驻，首次点击后消失；同一浏览器会按账号记住点击记录。小镇内可通过「返回」回到工作台首页。

## 主要体验

| 功能 | 用户能体验什么 |
| --- | --- |
| 地图探索 | 17 张地图相互连接，涵盖庭院、市集、河街、草原、森林、海域与天港。桌面支持鼠标点击寻路和键盘移动。 |
| 暖光会厅 | 从庭院大门进入，在壁炉旁落座，欣赏窗光、浮尘和垫子上睡觉的小猫。 |
| 居民互动 | 与镇长交流；点击阿砚、小苔、阿川、书禾，看到符合各自人设的固定问候，并有语音反馈。书禾会拿书、眨眼。 |
| 个人装扮 | 修改昵称和简介，选择或摘下六款配饰。 |
| 音乐氛围 | 九首小镇音乐，可跟随地图或手动选曲，配合动物、流水、风声等场景氛围。 |
| 任务提醒 | 头顶标签展示本人创作任务的进行中、完成或失败状态，点击可返回相关创作位置。 |
| 聊天体验 | 可体验公聊、私聊申请和回复流程，目前内容与交流仍是本地演示。支持按需翻译单条消息为中文或英文，需模型服务可用。 |

## 运营介绍建议

**推荐文案：**「等作品生成的片刻，去 Piko 小镇散散步。逛一逛庭院，听一首小镇旋律，或者在暖光会厅里坐一会儿。」

内容展示可优先围绕三个主题：

- **小镇漫步**：初遇庭院、匠作市集、灯河街的连续探索。
- **窗边休憩**：暖光会厅、睡猫、壁炉、座椅与拿书的书禾。
- **创作陪伴**：等待任务时逛小镇，任务状态变化后点击提醒返回创作。

## 当前体验边界

- 真实多人同地图、用户间公聊和私聊尚未接入。NPC 问候为预设台词。
- 角色资料与配饰主要保存在当前浏览器，换设备不会自动同步。当前每次进入仍重走入场与角色创建，重新创建时会重置个人简介。
- 场景完善程度有差异：庭院、市集、灯河街、云顶坡、琥珀原野及暖光会厅的互动和空间限制较完整，其余地图目前以观光为主。
- 当前主要适合桌面浏览器，手机触屏移动尚未接入；装扮主要为配饰，扩展服装尚未开放。

## 后续重点

1. **先改善回访体验**：老用户直接进镇，保留已有角色和个人资料。
2. **再接入真实社交**：明确在线居民、聊天申请和消息规则，再规划社交活动。
3. **持续完善场景**：补齐地图互动和手机操作，让不同区域都有值得停留的内容。

建议后续观察入口点击量、成功进镇比例、任务提醒返回次数和再次到访情况；目前尚未形成专门的小镇运营数据报表。
