# 小镇五区性能与声音验收 — 2026-09-12

本机桌面采样未观察到持续掉帧或切图资源累积；用户试听喷泉旁、庭院右侧河边和西南虫鸣区后确认「听感都没问题」。现有音量、播放频率及音频文件保持不变。下一步进入 [BGM 分组与生成准备](bgm-plan-v1.md)。

## 测量范围

- Apple M1 Pro，Chrome 153，WebGL 2 / ANGLE Metal；本地 Vite 开发服务、已热缓存资源。地图绘制范围 1280×720，分别测 DPR 1 和 DPR 2。
- 独立页面挂载实际 `PikoWorldCanvas` 与共用 BGM，记录 Pixi ticker、Assets、音频、定时器以及浏览器性能数据。未测完整页面外壳的整体开销；未截图。
- 五图各采样 8 秒，再连续重挂载 18 次、庭院驻留 2 分钟，补测移动、减少动态和后台恢复。重挂载检查不等于自动步行经过全部出口。
- ready 每约 50ms 轮询；不含产品黑场与标题停留时间，不代表首次网络下载耗时。CPU 指标包含帧内更新与渲染提交，不是 GPU 执行时间。

## 切图、驻留与暂停

- 连续 18 次重挂载均 ready，始终只有一个地图 Canvas / Pixi 实例；庭院保持 31 张资产纹理，其他图恢复为 4 张。ready 范围 101–545ms。
- 强制 GC 后，庭院回访堆内存从约 47.3MiB 缓慢增至 48.9MiB；随后驻留的四个 30 秒段为 49.41、49.50、49.65、49.69MiB，趋于稳定。监听数量在同类地图回访时保持一致。此短时结果不构成不存在内存泄漏的证明。
- 庭院驻留期间帧间隔 P95 为 16.7–16.8ms；移动采样 CPU P95 为 1.2ms。驻留段未持续解锁完整环境音混合，音频后台恢复另行验证。
- 减少动态后，ticker 回调由 51 降至 9，CPU P95 为 0.7ms；纹理预算不变，当前选项减少动画而不卸载静态资产。
- DPR 2 补测庭院与码头，帧间隔 P95 都为 16.7ms，CPU P95 分别为 1.4、0.7ms，没有长任务或超过 33.4ms 的间隔。跨段 CPU 波动不代表 DPR 2 比 DPR 1 更快。
- 实际切到另一标签页后，`document.hidden=true`，5 秒内零帧、无播放中的 HTML 音频；返回后 BGM、喷泉和鸟鸣恢复，ticker 回调恢复为 51。后台保留资产和 AudioContext 是暂停语义。
- 卸载后地图实例、Canvas、ticker 回调、加载资产、定时器、带源音频及 AudioContext 均为零。显式全局监听仅余 React 的 `selectionchange` 单例。

## 声音与听感

用户确认三个指定位置听感正常，未提出过吵、过密或久听疲劳问题，因此不调整已有混音。

离线响度测量按配置增益计算单条素材，不是现场总混音，也未测扬声器或耳机声压。BGM 平均约 -29.7dBFS、峰值 -16.2dBFS；喷泉、河流、风叶平均约 -38.5 至 -39.4dBFS。小牛单声平均约 -21.8dBFS，第三条脚步平均比另外两条高约 7–9dB；这些差异仅记录，结合用户验收保留现状。

可行走区以 24px 网格抽样 2708 个点，在增益 ≥0.01 的口径下最多叠加三层连续环境声（不含间歇鸟鸣）。典型位置：

| 位置 | 环境声配置衰减后的增益 |
| --- | --- |
| 喷泉旁 | 喷泉约 0.282；间歇鸟鸣 0.12 |
| 右侧河边 | 河流约 0.255、风叶约 0.074；间歇鸟鸣 0.12 |
| 西南虫鸣区 | 风叶 0.14、虫鸣 0.16；间歇鸟鸣 0.12 |

另有 BGM 0.16、行走时脚步以及偶发动物声。动物调度同时最多一个待播／播放声，全局静默间隔 5 秒、各动物冷却约 20–75 秒；鸟鸣片段约 30 秒，结束后间隔 60 秒。私聊通知沿用 BGM 0.16→0.07 的临时压低与恢复。

声音验收覆盖当前实际内容；其他四区仍共用 BGM 和脚步，尚未配置独立环境声。移动端、低端设备、冷启动、长时间驻留及未来十五图完整动态不在本次通过范围。
