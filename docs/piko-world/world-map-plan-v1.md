# Piko 世界地图规划 v1

状态：十五张区域母稿的风景化最终版均已入库；当前进入 B06–B09 模块化地形组件阶段。

## 核心原则

- Piko 小镇不是任务驱动的传统游戏世界，而是供用户长期停留、独处、放松与自然交流的共享空间；每张地图即使移除任务和交互仍须具备独立、耐看的景观价值。
- 地图以自然风景的美感为首要视觉目标；呼吸感来自大尺度留白、疏密节奏和远近层次，生命感来自光、水、风与植被的自然关系，不以堆叠装饰、设施或玩法节点制造丰富度。
- 初遇庭院是 Piko 小镇的中央起点，不是孤立地图或世界边界。
- 地图使用统一 32 px 逻辑地块、低俯角斜俯视视角和连续世界坐标；实现时由镜头跟随与分区加载组织，不生产一张不可拆分的巨幅背景。
- 小镇各区遵循“70% 共用素材＋30% 地标素材”：草地、道路、建筑材质、树木、路灯、标牌和边界组件连续；每区只用一个主要地标和少量专属设施建立记忆点。
- 主路、河岸、栅栏与建筑基线必须在相邻区边缘对齐，玩家向左或向右移动时不出现风格、比例或透视跳变。
- 日夜共用中性基础素材；全局夜色、暗角和光照范围由运行时实现，只为窗户、门灯、路灯等制作可对齐的发光状态。

```text
西线：初遇庭院 → 匠作市集 → 风庭门 → 低语草甸 → 低语森林
东线：初遇庭院 → 灯河街 → 星灯码头 → 星落潮汐湿地 → 星痕海岸 → 无垠海域
南部闭环：初遇庭院 → 琥珀原野 → 赤霞峡谷 → 星痕海岸
天空彩蛋线：云顶坡观星台 ⇢ 鲸歌天港；首次发现后解锁快捷传送
```

小镇五区、九张野外母稿与鲸歌天港共十五张区域母稿已完成风景化复核并封版，后续统一从最终母稿提取和生产可复用组件。

野外允许拥有独立植被、地表和地标素材；相邻区域优先通过地形、色彩、植被和自然路径连续过渡，仅在小镇边界保留必要且克制的共用设施。

F06 使用轻型小船航行。船体采用简洁叶片轮廓、单短桅和小型帆，无船舱、甲板层与复杂机械，容量控制为 2–4 人；地图母稿只确定船只尺度和视觉方向，正式移动、上下船、碰撞与海流规则在玩法阶段实现。

## 特殊社交地图

| 地图 | 定位 | 核心景观 | 观赏重点 |
| --- | --- | --- | --- |
| 鲸歌天港 | 隐藏在云海之上的多人聚集空间 | 风帆广场与天空鲸远景 | 悬浮岛轮廓、云海纵深、空中尺度与色彩变化 |

鲸歌天港采用一座占主要面积的连续悬浮主岛和少量近距离卫星岛。裸露岩层、倒悬根系、穿岛云流和远近视差共同建立悬浮感；天空鲸作为远景生命景观经过，不承担触发事件，也不占据画面主体。天港只使用轻型木构、彩色风帆和系云柱，不复刻星灯码头，也不引入大型飞艇、复杂机械、任务机关或游乐设施。地图首先是一幅可进入、可停留的空中风景，社交发生在景观之中，而不是由玩法驱动。

## 小镇连续性契约

- 共用色彩：奶油白墙面、深海军蓝／青绿色屋顶、暖木、金色五金、森林绿植被、砖红和紫色点缀。
- 共用道路：主石板路始终保持同一宽度与铺装节奏；支路可切换为碎石、木桥或土路。
- 共用建筑语言：一至两层小体量、清晰门窗、非对称屋顶、克制的叶片／灯光徽记；禁止突然出现现实摩天楼或完全不同的文明尺度。
- 共用尺度：门、长椅、栏杆和摊位均以 56 px 人类居民为尺度依据；所有场景概念不得随意放大角色或建筑。
- 共用密度：保留清晰通行区和必要连接，以疏密节奏形成可停留空间，避免巨大空广场或装饰塞满可行走区域。
- 共用通行：跨区主路和主要出口的净宽不得低于 4 个 32 px 地块，桥面不得低于 3 个地块，支路不得低于 2 个地块；保证多名居民会合时不形成单点堵塞。
- 共用遮挡：一至两层主体建筑优先放在画面北侧／后景；南侧／前景只放低矮围栏、花草和可穿越的小型设施，禁止高建筑或大树遮挡主路与区域出口。
- 场景总览只负责布局和视觉方向；最终游戏地图由无缝地块、模块化建筑、植被和设施组合完成。
