# Piko 世界地图规划 v1

状态：小镇五区母稿已完成；当前生产四张野外大地图母稿，全部通过后再进入模块化组件阶段。

## 核心原则

- 初遇庭院是 Piko 小镇的中央起点，不是孤立地图或世界边界。
- 地图使用统一 32 px 逻辑地块、低俯角斜俯视视角和连续世界坐标；实现时由镜头跟随与分区加载组织，不生产一张不可拆分的巨幅背景。
- 小镇各区遵循“70% 共用素材＋30% 地标素材”：草地、道路、建筑材质、树木、路灯、标牌和边界组件连续；每区只用一个主要地标和少量专属设施建立记忆点。
- 主路、河岸、栅栏与建筑基线必须在相邻区边缘对齐，玩家向左或向右移动时不出现风格、比例或透视跳变。
- 日夜共用中性基础素材；全局夜色、暗角和光照范围由运行时实现，只为窗户、门灯、路灯等制作可对齐的发光状态。

## 小镇连续性契约

- 共用色彩：奶油白墙面、深海军蓝／青绿色屋顶、暖木、金色五金、森林绿植被、砖红和紫色点缀。
- 共用道路：主石板路始终保持同一宽度与铺装节奏；支路可切换为碎石、木桥或土路。
- 共用建筑语言：一至两层小体量、清晰门窗、非对称屋顶、克制的叶片／灯光徽记；禁止突然出现现实摩天楼或完全不同的文明尺度。
- 共用尺度：门、长椅、栏杆和摊位均以 56 px 人类居民为尺度依据；所有场景概念不得随意放大角色或建筑。
- 共用密度：保留清晰通行区和回环路线，避免巨大空广场，也避免装饰塞满可行走区域。
- 共用通行：跨区主路和主要出口的净宽不得低于 4 个 32 px 地块，桥面不得低于 3 个地块，支路不得低于 2 个地块；保证多名居民会合时不形成单点堵塞。
- 共用遮挡：一至两层主体建筑优先放在画面北侧／后景；南侧／前景只放低矮围栏、花草和可穿越的小型设施，禁止高建筑或大树遮挡主路与区域出口。
- 场景总览只负责布局和视觉方向；最终游戏地图由无缝地块、模块化建筑、植被和设施组合完成。
