# 庭院河鱼

每张横排4帧，按实际透明边界创建纹理裁片，使用鱼头及身体中线对齐，物种内保持固定缩放。渲染与资源生命周期见 `runtime/map-river-fish.ts`，随机路线与避让逻辑独立在 `runtime/river-fish-motion.ts`。

桥下到下游的连通河道放3条青灰鱼（长24.48–26.52世界像素）和1条浅金鱼（长28.56世界像素），均较上一版放大2%。河面动画维持16帧、2fps的8秒缓流循环；青灰鱼摆尾为2.5–2.8fps，金鱼为2.3fps，四者错相。每条鱼以16–24世界像素/秒游动，每5.5–10秒或接近目标时重新选点；到达目标后有42%概率静止2–5秒，静止时保持首帧，水纹继续覆盖鱼身。72%目标向下游偏移，其余保留逆流或横切。转向限制为1.8弧度/秒，目标和行进方向检查河岸余量；目标搜索失败后等待750ms再试，目标间距无法满足时选用可安全到达的备用点。近距离主动避让，移动时保持至少28世界像素的中心间距。未包含觅食或追逐行为。

复用环境配置中的 `river-water-*` 多边形裁切，鱼层深度为-0.9，位于水面基础动画之上、岸边景物之下；再在鱼上方叠加5%不透明度的同帧河水纹理，形成水下效果。鱼本体使用水色染色与适度透明度，不加气泡、发光或尾迹。范围测试覆盖四组固定随机种子各连续10分钟游动，检查河面范围、移动连续性、间距和平均速度。

初遇庭院与灯河街都从庭院资源路径加载两份共享图集，离开地图释放纹理租约、裁片、遮罩和ticker回调。页面隐藏或减少动态效果时移除逐帧回调，恢复后重新挂载；减少动态效果时固定鱼位和首帧。自动检查覆盖资源与运行行为，最终视觉由用户验收。

灯河街复用这两张四帧鱼图集与相同的贴图裁切、5%水纹薄罩、摆尾和避让机制。上游放2条青灰鱼，下游放2条青灰鱼和1条浅金鱼，右下浅滩放2条较小的青灰鱼；三处水域分别约束路线，鱼身保持15世界像素岸线余量，鱼之间保持至少28世界像素中心距。浅滩鱼主要沿岸横向游动，避免靠近木栈道与岸石。离开灯河街同样释放纹理租约、遮罩与ticker回调。

水域由环境运行时直接提供具名水面与动画精灵；鱼群通过 `surfaceId` 绑定环境效果 ID，不依赖数组顺序或显示容器的子节点位置。两图共用资源 URL 与纹理租约，灯河街不再保存重复鱼图集。
