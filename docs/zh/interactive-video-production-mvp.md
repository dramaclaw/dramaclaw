# M6 视频生产 MVP 实施计划

> 最近对账：2026-10-12。制作数据与现有执行入口已接入；真实 Agent、媒体生成及完整作品仍待验收。

目标：剧情节点 → 制作说明 → 视频提示词 → 提交生成 → 回填 → 试玩。
复用现有视频节点、生成接口、任务系统和素材能力，不新建一套生产系统。
本阶段不做 QTE、第三方插件、复杂分镜编辑器或完整素材版本平台。

## 分步交付

| 步骤 | 范围 | 验收 | 状态 |
| --- | --- | --- | --- |
| 1 制作数据链路 | Agent 写制作说明与独立提示词；画布双向映射；执行消费节点提示词 | Create/Get/Patch 不混淆剧情与提示词；缺提示词不提交生成 | 已实现，模型与服务回归通过；真实 Agent 待验收 |
| 2 单节点生产 | 复用现有节点生成、导入、替换、历史和任务恢复 | 生成成功回填当前节点；失败保留旧素材；删除或编辑中的节点不会被过期结果覆盖 | 现有能力已接入；真实失败/重试、刷新恢复与过期回填待验收 |
| 3 实时生成入口 | “从此生成”打开当前节点编辑与生产操作；按节点核验模型、时长、比例与音频能力 | 不重写下游剧情；生成前确认配置；完成后可在预览播放 | 入口与制作引导已实现；完整生成/播放待验收 |
| 4 批量与状态变体 | 通过现有 Workflow 提交已授权且就绪的节点；参考图/分镜映射回片段 | 不重复生成已有视频；不同状态视频不串绑；批次结果可定位 | Agent 批次与图片映射已接入；状态变体及完整素材版本闭环待收口 |
| 5 示例与端到端验收 | 现有互动广告逐段准备、生成、回填、试玩 | 至少两个结局；分支衔接合理；横竖屏与选择尾帧可用 | 待实施 |

每一步先定向回归，再进入下一步；真实生成可能产生费用，应使用用户确认的
模型与预算进行验收。完成提示词准备不代表已执行生成，也不代表画面质量已验证。

## 第一步的最小方案

现有画布已有 `narration`、`storyProductionNotes`、`prompt`，不增加重复编辑表单。
保持现状会让批量生成直接提交剧情旁白；全面增加分镜模型会扩大 MVP 范围。
采用最小增量：领域 Segment 新增 `video_prompt`，映射现有 `prompt`，生成消费
节点提示词。制作说明暂用现有文本字段，以规范化内容组织而非新增复杂 schema。

| 领域字段 | 画布字段 | 内容 |
| --- | --- | --- |
| `script` | `narration` | 玩家看到或听到的剧情 |
| `production_notes` | `storyProductionNotes` | 场景、角色外观、动作、镜头、声音意图、开场、收尾、连续性 |
| `video_prompt` | `prompt` | 可直接提交视频模型的当前片段画面描述 |

制作说明由 Agent 在用户要求准备视频时整理，视频提示词由 Agent 基于说明编写；
本轮不新增自动调用模型的“转换”接口。用户也可在现有节点提示词中手动修改。
提示词缺失或空白的片段保持待准备，不能回退为剧情旁白或制作备注；普通单节点视频生成继续复用既有能力。
修改剧情不会偷偷改提示词或重生成视频；过期提示词检测留待后续，不将其视为已实现。

### 制作约束

- 默认选项、倒计时由播放器绘制，不生成进视频；条件与状态由剧情运行时处理。
- 选择节点结尾适合定格，不要求主视频无缝循环。
- 汇合节点考虑多个前驱的共同开场；状态变体共享角色、场景、风格描述。
- 参考素材必须真实存在；提示词中的描述不等同于已绑定参考图片。
- 时长、比例、模式、声音和参考数量按实时模型目录逐节点核验；不使用整部共享时长或固定无音频批量配置。
- 准备或修改提示词不替换素材，不删除分支，不自动消耗生成额度。

## 当前执行入口与边界

- 原故事组“缺失片段批量生成”面板已移除，不把它列为当前入口。Agent 使用一次 `freezone_run_workflow(node_ids=[...], direction="node", regenerate=false)` 提交本批已授权、就绪且尚无视频/未在生成的节点；重做仅针对明确授权的节点。
- 角色、产品、场景和独立开场分镜图片通过已有 Workflow 创建，使用稳定 story/segment/video 映射；图片真实完成后回读引用，不把“已提交”当成素材就绪。
- “从此生成”只定位并打开当前片段编辑态。自动承接只依赖真实媒体连线及显式 `continuityMode=auto`，不从剧情边推测生成依赖。
- 失败不自动重试或改提示词；用户明确要求重试后再提交。现有节点历史/任务恢复不等于已交付完整素材版本与成本平台。

行为约束见 [制作规划](../../src/novelvideo/agent_skills/interactive-story/references/production-planning.md)、[分镜图片批次](../../src/novelvideo/agent_skills/interactive-story/references/storyboard-frames.md) 与 [生成执行](../../src/novelvideo/agent_skills/interactive-story/references/generation-execution.md)。

### 第一步验收（初次交付）

- 模型校验：视频提示词长度受限，剧情内容独立保存。
- 服务回归：提示词创建、读取、修改、清空；修改剧情保留提示词、媒体和连线。
- 前端回归：批量计划只使用独立提示词；空白、错误类型跳过；已有视频、生成中和非组节点排除。
- 人工待验收：在项目内让 Agent “只为一个片段准备制作说明和视频提示词，先不生成”，检查画布内容后再执行单节点生成。

- 前端批量计划：5 项通过；TypeScript 项目检查通过；差异空白检查通过。
- 未执行真实 Agent 对话、付费视频生成或浏览器端到端验收；尚不能据此认定生成质量与整条生产链路通过。

### 当前剩余验收

- [ ] 用真实 Agent 为一个片段只准备制作说明与提示词，再经授权执行生成，确认参数与真实引用一致。
- [ ] 验证导入/生成混用、失败保留旧素材、用户触发重试、刷新恢复，以及节点删除/更换任务后的过期结果保护。
- [ ] 验证参考图/分镜完成后接回正确片段，缺图及失败片段保持待准备，批次不重复覆盖已完成视频。
- [ ] 用至少两个结局的完整作品核验首尾与汇合衔接、声音、横竖屏、选择尾帧和发布/离线播放。
- [ ] 补齐剧情修改后的提示词过期检测、状态变体归属及素材版本恢复规则；当前不将这些视为已实现。
