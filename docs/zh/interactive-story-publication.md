# 互动影游分享发布

故事组工具栏的「发布作品」提供发布管理。首次发布填写信息后「检查并准备」，准备完成停留在结果页，由作者点击「预览作品」，先查看与玩家一致的作品首屏，再开始试玩和确认发布。已有作品默认进入发布管理，固定展示当前版本、分享链接和历史记录；「准备新版」只准备内容，不立即上线。待发布任务可继续准备或预览。发布的是准备时保存的画布版本；后续编辑不会改变已准备或已发布内容。必需视频、无效分支、未配置结局等问题阻断发布，不可达片段作为警告。

## 部署

分享链接自动使用当前浏览器页面的协议、域名和端口，拼接 `/play/{publicId}`，无需配置站点地址。

使用 localhost / 127.0.0.1 / ::1 打开时，链接仅供本机访问。给其他人分享时，请从对方可访问的域名打开本站；手机打开链接时也应使用手机可访问的地址。自动生成链接不会自动建立公网隧道，也不代表公网可达性已验证。

发布快照、媒体和准备任务统一保存在 `<项目 state_dir>/publications/<作品ID>/<版本ID>/`，随项目一起备份、恢复和永久删除。全局 `${NOVELVIDEO_STATE_DIR}/publications` 仅保留公开作品 ID → 项目 ID 索引和跨目录移动期间使用的锁；`ST_PUBLICATION_DIR` 现在只指定该索引和锁目录，不再指定媒体存储位置。所有 API worker 需访问一致的项目数据及索引目录，文件系统需支持文件锁。

当前处于开发阶段，不迁移或读取旧全局目录中的发布记录，旧作品需重新发布。暂不处理发布期间的服务重启和停机恢复，不在应用启动时扫描未完成任务。作者打开发布面板会重建对应项目的公开索引。

前端服务需要将 `/play/*` 回退到 SPA 入口，并代理 `/api/v1/public-stories/*` 至 API。现有前端 nginx 的 SPA 回退覆盖该路由。网站应通过公网 HTTPS 提供服务；本功能不会创建隧道或修改域名。

## 内容与版本

第一版媒体必须已归档在本项目 output 目录，并使用 `/api/v1/projects/{project}/media/...` 或 `/static/projects/{project}/...` 相对地址。封面支持 PNG/JPEG/WebP，每个版本选择横版 16:9 或竖版 9:16，可调整左右及上下取景位置；编辑缩略图、作者预览与玩家首屏共用相同比例和取景参数，不改变视频播放方向。视频支持 MP4/WebM/MOV（实际播放能力取决于浏览器编码支持）。外部 URL、带凭据的临时链接及跨项目资源需先通过项目上传功能归档。发布复制媒体后使用独立版本资源，避免草稿覆盖或删除导致线上资源失效。

准备任务状态和输入持久化，同一任务通过文件锁防止重复执行。已接收的后台准备任务遇到项目锁或任务锁超时会自动重试，锁释放后继续执行；等待期间项目目录已被永久删除流程移走时，任务退出且不会重建项目目录。API 操作仍在锁超时后返回忙碌错误。服务重启后不自动续跑，中断的任务可能保留在准备中状态。准备时记录媒体文件身份、大小和修改时间等指纹，复制前后均校验；若准备期间被覆盖，则失败并要求重新准备。旧的未完成任务若缺少来源指纹，也需重新准备。准备失败保留原上线版本并清理失败任务媒体；通过再次准备重试。网络响应丢失时复用原请求 ID 和参数，已接收的请求不受后续画布 revision 变化影响；重新打开发布面板可查看已保存的待发布任务。

作者预览使用实际 Ink 编译结果，编译失败时不允许确认发布。发布、回退和上下架通过原子替换一个作品记录生效，该记录同时保存当前版本、已发布版本集合及上下架状态，版本快照不随发布切换改写。本功能尚未正式发布，不支持开发期间的旧格式记录。

固定链接为 `/play/{随机作品标识}`。游客接口仅返回播放快照和作品信息，无公开作品列表。拥有链接的人可免登录读取内容；下架阻断后续作品、历史版本和媒体请求，无法撤回浏览器已经下载的数据。

新版本在首次成功发布时分配正式版本号并记录发布时间，准备、失败和重试不占正式版本号。切换历史版本保留原版本号和发布时间，也保持当前上下架状态；重新上架需单独操作。

存档留在玩家浏览器，按作品和版本隔离。继续游玩使用原版本，重新开始使用当前版本。浏览器存储不可用时仍可游玩，但无法保存进度。已发布历史版本与媒体保留用于回滚，运维需关注磁盘空间。未发布草稿在准备任务结束后自动清理：保留最新准备结果与最新可用版本，新检查失败不会删除上一份可用草稿；作品存在未完成任务时暂缓清理，保护其引用的素材。被替代草稿的版本目录与媒体一并删除，仅保留请求摘要以阻止旧请求重试重新生成副本。其他窗口中已被替代的草稿需重新检查。

## 接口

作者接口位于 `/api/v1/projects/{project}/canvases/{canvas}/stories/{group}/publication`，要求 editor 或更高权限：GET 管理信息、POST `/prepare` 准备、GET `/{publicId}/versions/{version}` 查询与预览、POST `/{publicId}/activate` 发布/下架/回退。预览媒体通过同一路径下的版本媒体接口鉴权读取。

游客接口为 GET `/api/v1/public-stories/{publicId}`、GET `/versions/{version}` 和 GET `/versions/{version}/media/{asset}`；只允许已发布且作品未下架的版本，媒体提供 Range 支持和 no-store 缓存策略。


同一版本内引用同一源视频（包括主片与选择循环）时只保存一份媒体副本，不同发布版本仍独立归档。
项目移入回收站会下架作品；项目删除状态统一读取项目注册表，不另存发布删除状态。恢复项目保留下架状态，需作者手动重新上架。新的准备和发布在文件锁内核验项目状态；删除登记失败时补偿恢复原上架状态。永久删除复用项目原有的目录隔离、清理与失败恢复流程，不再单独搬移发布目录；项目目录移动与发布复制共用一把锁，复制任务仍占用时返回忙碌错误，请稍后重试。公开访问每次检查项目注册表，项目已删除、已清除或不属于当前节点时拒绝访问，即使残留索引也不能继续播放。
