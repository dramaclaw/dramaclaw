# 互动影游 HTML 导出

试玩与导出共用 `../StoryExperience.tsx`（剧情探索、回溯、全屏）和 `../StoryPlayer.tsx`、`../storyPlayer.css`、`storyRuntimeStore` 和选择点状态机。
`StoryPlayerOverlay` 只负责创作者外壳（返回画布、故事树、调试控制、统计）。不要再手写一套导出播放器。

- `build/storyPlayerPlugin.ts` 在开发和正式构建中，把 `standalone.tsx` 及共享组件打包成 IIFE 与 CSS，通过虚拟模块交给 `buildPlayerHtml`。没有需要提交或手工更新的生成产物。HTML 打包模块按需加载。
- 导出包含编译后的可达剧情分支图与当前语言的探索文案，支持查看解锁进度、从已解锁片段重玩、返回选择点和清除探索进度。探索状态仅保留在本次打开的页面内，刷新后从头开始。
- `standalone.tsx` 将预编译 Ink JSON 和媒体表交给同一个运行时。Ink 版本来自锁文件中的依赖，不再维护 vendored runtime。独立文件从起点开始，不读取创作者的试玩存档或统计。
- 互动影游与互动广告的故事组工具栏提供“导出离线包”，按当前画布快照编译，不需要先发布。
- `buildStoryZip.ts` 使用 zip.js 顺序读取主视频和互动循环视频，原样存入 ZIP 的 `videos/`，重复 URL 只打包一次；不做 Base64 编码，不再次压缩视频。ZIP64 由库自动处理。
- 根目录 `index.html` 内联播放器、剧情、探索地图和文案，通过相对路径加载视频，不需要 fetch 本地 JSON、服务器、登录或 CDN。完整解压后打开 `index.html` 即可使用，不能单独移动 HTML。附带 `README.txt` 使用说明。
- 导出显示媒体下载进度，视频下载失败不会下载不完整的 ZIP。不设固定容量上限；当前下载出口使用 BlobWriter 保留最终 ZIP，仍受浏览器可用存储/内存约束，不宣称无限容量或直接流式写磁盘。广告外部 CTA 链接仍需要网络。
- 试玩、实时生成和导出都把整个播放器（含选项、热点与结局）按主视频比例限制在可用视口内，选项不会延伸到视频两侧的留白区域。
- 两个入口都完整展示视频（`object-fit: contain`），锚点按实际画幅和留白换算；旋转或容器变大变小时重新测量。选项区域限制高度并允许滚动，低矮横屏可两列排布。
- 自动播放被拦截时提供播放按钮；视频失败提供重试；独立循环片段失败回退主视频尾帧；视频结局等待媒体播放结束。

验证：`buildPlayerHtml.test.ts` 检查数据与注入边界；`exportPlayer.runtime.test.ts` 实际执行导出 HTML；`StoryPlayerOverlay.choicePhase.test.tsx` 和运行时测试覆盖共享播放行为。浏览器验证还需检查有声视频、横竖屏切换和热点点击。

实时生成的“从此生成”定位并打开当前片段编辑态，复用节点提示词与视频生成操作；不会自动生成后续剧情。QTE、素材管理、发布运营与完整产品验收留待后续。
