# Ad Video Workflow

用于广告视频、投放素材、短视频广告。

## 材料要求

- 必需其一：产品图片、商品图、产品 brief、商品链接、已有产品说明，或用户在聊天里描述的产品。
- 推荐：目标用户、核心卖点、投放平台、成片时长、画面比例、品牌调性、CTA。
- 可选：参考广告、禁用词、价格/优惠、竞品、口播风格、字幕语言、A/B 版本数量。

如果只有产品图，也可以开始规划，不需要剧本；先创建图片输入、视觉理解、卖点提炼和 Hook 分支。

## 生产链路

`产品输入/图片素材 -> 视觉理解 -> 受众分析 -> 卖点提炼 -> Hook 方案 -> 广告脚本 -> A/B 版本 -> 镜头脚本 -> 图片/视频资产 -> 口播/音乐 -> 成片合成 -> 复盘优化`

## 动态展开

- 用户只有产品图时，从 `product_image_input` 和 `visual_analysis` 开始。
- 用户有产品 brief 时，从 `product_brief` 开始。
- 多个平台时，按平台拆 Hook、比例、时长和 CTA。
- A/B 测试时，每个 Hook 或核心卖点形成一个版本分支。
- 不要生成短剧式角色/分集结构，除非用户明确要求剧情广告。
