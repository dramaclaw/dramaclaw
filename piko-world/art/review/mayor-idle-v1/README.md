## 本轮制作

- `approved-reference.png`：用户确认的形象母稿副本，保留原始文件，不改稿。
- `mayor-south-master-64.png`：64×64 RGBA 母帧，最近邻整理、统一 21 色调色板、清理半透明边缘、修正轮廓及双眼高光。静态可见高度 48 px。
- `frame-00.png` 至 `frame-06.png`：7 张独立姿态；基础站立、吸气叶片滞后、吸气、叶片回落、呼气叶片滞后、半闭眼、闭眼。
- `mayor-idle-sheet.png`：448×64 RGBA 横排图集。
- `mayor-idle.json`：帧坐标、叶片挂点、脚底轴心、15 段非等时播放序列及源文件摘要。
- `mayor-idle-*-sheet.png`：body、outfit、prop、leaf 对齐图层；prop 包含持书手部像素，便于一起移动。分层重组与合成帧逐像素一致。

呼吸时上身和书本以整数像素上移 1 px，衣摆下缘及脚部不动；叶片自由端延迟响应。眨眼独立修改双眼区域，不改变身体或轮廓。循环总时长 5280ms，首尾为同一基础站姿。无运行时拉伸、旋转、倾斜或平滑补帧，不招手。问号与接触阴影不包含在图集中。

当前是从母稿确定性整理的首版像素动画，并非已由用户验收的最终动画。衣服细节在 48 px 高度下已简化，需重点确认小尺寸观感。

## 重建与检查

在仓库根目录运行：

```sh
.venv/bin/python scripts/build_piko_mayor_idle.py
.venv/bin/python -m unittest discover -s scripts -p test_build_piko_mayor_idle.py
```

脚本仅重建本目录的派生文件，不修改已确认参考图或游戏运行素材。检查内容：64×64、二值 Alpha、统一调色板、7 张非重复帧、脚底基线 y=57、衣摆与脚部固定、眨眼仅修改眼区、图层无损重组、确定性输出及播放序列闭合。
